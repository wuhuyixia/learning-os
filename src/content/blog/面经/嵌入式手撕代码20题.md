# 嵌入式手撕代码 20 题：位运算、字符串、宏与链表

嵌入式面试里的“手撕代码”通常不会追求特别复杂的算法，重点更偏向 **C 语言基本功、边界条件、位操作、指针和链表**。

下面整理 20 道高频题。每题都给出可以直接使用的 C 代码，并补充最容易被追问的细节。

## 一、位运算类

### Q1：判断一个整数是不是 2 的整数次幂

**思路：** 2 的整数次幂在二进制中只有一个 bit 为 1，例如：

~~~text
1  = 0001
2  = 0010
4  = 0100
8  = 1000
~~~

因此对正整数有：

~~~text
n & (n - 1) == 0
~~~

**代码：**

~~~c
#include <stdint.h>
#include <stdbool.h>

bool is_power_of_two(uint32_t n)
{
    return n != 0u && (n & (n - 1u)) == 0u;
}
~~~

需要特别处理 0，因为 0 与减 1 后的结果做按位与也会得到 0。

### Q2：统计一个整数二进制表示中 1 的个数

可以使用 Brian Kernighan 算法。每执行一次：

~~~text
n &= n - 1
~~~

都会消掉最低位的一个 1。

**代码：**

~~~c
#include <stdint.h>

unsigned int count_bits(uint32_t n)
{
    unsigned int count = 0;

    while (n != 0u) {
        n &= (n - 1u);
        ++count;
    }

    return count;
}
~~~

例如：

~~~text
n = 10110000
    ↓
    10100000
    ↓
    10000000
    ↓
    00000000
~~~

因此一共存在 3 个 1。

### Q3：置位、清零、翻转、判断某一位

这是寄存器操作最常见的四件套。

**代码：**

~~~c
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>

void set_bit(uint32_t *reg, unsigned int bit)
{
    if (reg == NULL || bit >= 32u) {
        return;
    }

    *reg |= (1u << bit);
}

void clear_bit(uint32_t *reg, unsigned int bit)
{
    if (reg == NULL || bit >= 32u) {
        return;
    }

    *reg &= ~(1u << bit);
}

void toggle_bit(uint32_t *reg, unsigned int bit)
{
    if (reg == NULL || bit >= 32u) {
        return;
    }

    *reg ^= (1u << bit);
}

bool test_bit(uint32_t reg, unsigned int bit)
{
    if (bit >= 32u) {
        return false;
    }

    return ((reg >> bit) & 1u) != 0u;
}
~~~

示例：

~~~c
uint32_t reg = 0;

set_bit(&reg, 5);
clear_bit(&reg, 5);
toggle_bit(&reg, 3);
~~~

### Q4：求两个整数的平均值，要求不溢出

直接写：

~~~c
(a + b) / 2
~~~

存在 a + b 溢出的风险。

最直接可靠的办法是先提升到更宽的整数类型：

~~~c
#include <stdint.h>

int32_t average_int32(int32_t a, int32_t b)
{
    int64_t sum = (int64_t)a + (int64_t)b;
    return (int32_t)(sum / 2);
}
~~~

例如 a 和 b 都等于 INT32_MAX 时，32 位相加会溢出，而提升成 int64_t 后可以安全计算。

### Q5：不用临时变量交换两个整数

经典 XOR 交换：

~~~c
#include <stdint.h>
#include <stddef.h>

void xor_swap(uint32_t *a, uint32_t *b)
{
    if (a == NULL || b == NULL || a == b) {
        return;
    }

    *a ^= *b;
    *b ^= *a;
    *a ^= *b;
}
~~~

过程：

~~~text
a = a ^ b
b = a ^ b = 原来的 a
a = a ^ b = 原来的 b
~~~

实际工程里普通临时变量通常更清晰，XOR Swap 更适合作为位运算题。

### Q6：求一个数的绝对值，不允许分支判断

下面的写法不使用 if，并且对 INT32_MIN 也能得到正确的“无符号绝对值”。

~~~c
#include <stdint.h>

uint32_t abs_u32(int32_t x)
{
    uint32_t ux = (uint32_t)x;
    uint32_t sign = ux >> 31;
    uint32_t mask = 0u - sign;

    return (ux ^ mask) + sign;
}
~~~

原理：

~~~text
正数：
sign = 0
mask = 0
结果 = ux

负数：
sign = 1
mask = 0xFFFFFFFF
结果 = ~ux + 1
~~~

返回 uint32_t 是有意设计的，因为 abs(INT32_MIN) 的数学结果是 2147483648，无法用 int32_t 表示。

## 二、字符串与内存类

### Q7：手写 strlen

需要注意：

- 参数使用 const char *；
- 返回值使用 size_t；
- 下面实现额外对 NULL 做了防御性处理。

~~~c
#include <stddef.h>

size_t my_strlen(const char *s)
{
    const char *p;

    if (s == NULL) {
        return 0u;
    }

    p = s;

    while (*p != '\0') {
        ++p;
    }

    return (size_t)(p - s);
}
~~~

标准库 strlen 本身要求参数必须指向有效字符串，传入 NULL 属于非法调用；这里返回 0 是自定义的防御性策略。

### Q8：手写 strcpy、memcpy 和 memmove

这里最容易被追问的是：

> memcpy 遇到内存重叠怎么办？

答案是：**memcpy 不保证重叠安全，重叠时应该使用 memmove。**

#### strcpy

~~~c
#include <stddef.h>

char *my_strcpy(char *dst, const char *src)
{
    char *ret = dst;

    if (dst == NULL || src == NULL) {
        return NULL;
    }

    while ((*dst++ = *src++) != '\0') {
        /* copy */
    }

    return ret;
}
~~~

#### memcpy

~~~c
#include <stddef.h>

void *my_memcpy(void *dst, const void *src, size_t n)
{
    unsigned char *d = (unsigned char *)dst;
    const unsigned char *s = (const unsigned char *)src;

    if (dst == NULL || src == NULL) {
        return NULL;
    }

    for (size_t i = 0; i < n; ++i) {
        d[i] = s[i];
    }

    return dst;
}
~~~

#### memmove

~~~c
#include <stddef.h>
#include <stdint.h>

void *my_memmove(void *dst, const void *src, size_t n)
{
    unsigned char *d = (unsigned char *)dst;
    const unsigned char *s = (const unsigned char *)src;

    if (dst == NULL || src == NULL || dst == src || n == 0u) {
        return dst;
    }

    uintptr_t d_addr = (uintptr_t)d;
    uintptr_t s_addr = (uintptr_t)s;

    if (d_addr < s_addr || d_addr >= s_addr + n) {
        for (size_t i = 0; i < n; ++i) {
            d[i] = s[i];
        }
    } else {
        for (size_t i = n; i > 0u; --i) {
            d[i - 1u] = s[i - 1u];
        }
    }

    return dst;
}
~~~

核心区别：

~~~text
无重叠：从前往后复制即可

发生重叠且 dst 在 src 后方：
必须从后往前复制
~~~

### Q9：手写 strcmp 和 strstr

#### strcmp

~~~c
#include <stddef.h>

int my_strcmp(const char *s1, const char *s2)
{
    if (s1 == NULL || s2 == NULL) {
        return (s1 == s2) ? 0 : (s1 == NULL ? -1 : 1);
    }

    while (*s1 != '\0' &&
           (unsigned char)*s1 == (unsigned char)*s2) {
        ++s1;
        ++s2;
    }

    return (int)(unsigned char)*s1 -
           (int)(unsigned char)*s2;
}
~~~

#### strstr

~~~c
#include <stddef.h>

const char *my_strstr(const char *haystack, const char *needle)
{
    if (haystack == NULL || needle == NULL) {
        return NULL;
    }

    if (*needle == '\0') {
        return haystack;
    }

    for (const char *h = haystack; *h != '\0'; ++h) {
        const char *p = h;
        const char *q = needle;

        while (*p != '\0' &&
               *q != '\0' &&
               *p == *q) {
            ++p;
            ++q;
        }

        if (*q == '\0') {
            return h;
        }
    }

    return NULL;
}
~~~

### Q10：字符串转整数 atoi，处理正负号、非法输入和溢出

标准 atoi 无法可靠反馈错误，因此如果题目要求“处理非法输入和溢出”，更适合设计成带返回状态的版本。

~~~c
#include <stdint.h>
#include <stdbool.h>
#include <ctype.h>
#include <limits.h>
#include <stddef.h>

bool my_atoi(const char *s, int32_t *out)
{
    uint64_t value = 0;
    uint64_t limit;
    bool negative = false;
    bool has_digit = false;

    if (s == NULL || out == NULL) {
        return false;
    }

    while (isspace((unsigned char)*s)) {
        ++s;
    }

    if (*s == '+' || *s == '-') {
        negative = (*s == '-');
        ++s;
    }

    limit = negative ?
            ((uint64_t)INT32_MAX + 1u) :
            (uint64_t)INT32_MAX;

    while (isdigit((unsigned char)*s)) {
        unsigned int digit = (unsigned int)(*s - '0');
        has_digit = true;

        if (value > (limit - digit) / 10u) {
            return false;
        }

        value = value * 10u + digit;
        ++s;
    }

    if (!has_digit) {
        return false;
    }

    while (isspace((unsigned char)*s)) {
        ++s;
    }

    if (*s != '\0') {
        return false;
    }

    if (negative) {
        if (value == (uint64_t)INT32_MAX + 1u) {
            *out = INT32_MIN;
        } else {
            *out = -(int32_t)value;
        }
    } else {
        *out = (int32_t)value;
    }

    return true;
}
~~~

示例：

~~~c
int32_t value;

if (my_atoi("-12345", &value)) {
    /* value == -12345 */
}
~~~

### Q11：手写 memset

内存操作应该以字节为单位，因此转换成 unsigned char *。

~~~c
#include <stddef.h>

void *my_memset(void *ptr, int value, size_t n)
{
    unsigned char *p = (unsigned char *)ptr;
    unsigned char byte = (unsigned char)value;

    if (ptr == NULL) {
        return NULL;
    }

    for (size_t i = 0; i < n; ++i) {
        p[i] = byte;
    }

    return ptr;
}
~~~

需要注意：

~~~c
int a[10];
my_memset(a, 1, sizeof(a));
~~~

并不会把每个 int 变成 1，而是把每个字节都写成 0x01。

### Q12：判断字符串是否为回文

双指针从两端向中间移动即可。

~~~c
#include <stddef.h>
#include <stdbool.h>

bool is_palindrome(const char *s)
{
    size_t len;
    size_t left;
    size_t right;

    if (s == NULL) {
        return false;
    }

    len = 0u;
    while (s[len] != '\0') {
        ++len;
    }

    if (len < 2u) {
        return true;
    }

    left = 0u;
    right = len - 1u;

    while (left < right) {
        if (s[left] != s[right]) {
            return false;
        }

        ++left;
        --right;
    }

    return true;
}
~~~

例如：

~~~text
"level"  -> true
"abba"   -> true
"hello"  -> false
~~~

## 三、C 语言关键字与语法类

### Q13：用宏实现 offsetof 和 container_of

offsetof 用于得到结构体成员相对结构体起始地址的偏移量，container_of 则根据成员地址反推出整个结构体对象的地址。

~~~c
#include <stddef.h>

#define MY_OFFSETOF(type, member) \
    ((size_t)&(((type *)0)->member))

#define MY_CONTAINER_OF(ptr, type, member) \
    ((type *)((char *)(ptr) - MY_OFFSETOF(type, member)))

struct Device {
    int id;
    int status;
};

void example(void)
{
    struct Device dev = {1, 0};

    int *status_ptr = &dev.status;

    struct Device *owner =
        MY_CONTAINER_OF(status_ptr,
                        struct Device,
                        status);

    (void)owner;
}
~~~

实际工程中优先使用标准库 stddef.h 提供的 offsetof。Linux 内核的 container_of 还会借助 GNU 扩展做更严格的类型检查。

### Q14：用宏求最大值和最小值，并说明宏的坑

基本写法：

~~~c
#define MAX(a, b) (((a) > (b)) ? (a) : (b))
#define MIN(a, b) (((a) < (b)) ? (a) : (b))
~~~

括号必须尽量完整，否则会受到运算符优先级影响。

但是这种宏仍有副作用问题：

~~~c
int i = 1;
int j = 2;

int m = MAX(i++, j++);
~~~

展开后参数可能被求值多次。

工程代码更推荐类型明确的 static inline：

~~~c
static inline int max_int(int a, int b)
{
    return a > b ? a : b;
}

static inline int min_int(int a, int b)
{
    return a < b ? a : b;
}
~~~

### Q15：用宏实现指定位的置 1、清 0、翻转和读取

~~~c
#include <stdint.h>

#define BIT(n)              (UINT32_C(1) << (n))

#define SET_BIT(reg, n)     \
    ((reg) |= BIT(n))

#define CLEAR_BIT(reg, n)   \
    ((reg) &= ~BIT(n))

#define TOGGLE_BIT(reg, n)  \
    ((reg) ^= BIT(n))

#define READ_BIT(reg, n)    \
    (((reg) >> (n)) & UINT32_C(1))
~~~

示例：

~~~c
uint32_t reg = 0;

SET_BIT(reg, 3);
CLEAR_BIT(reg, 3);
TOGGLE_BIT(reg, 5);

if (READ_BIT(reg, 5)) {
    /* bit5 == 1 */
}
~~~

这里默认 n < 32。实际寄存器宏还需要结合寄存器宽度限制 bit 范围。

### Q16：函数指针与回调机制

函数指针的核心形式是“返回值类型 + 指向函数的指针 + 参数列表”。下面实现一个完整的事件回调示例。

~~~c
#include <stdio.h>
#include <stddef.h>

typedef void (*event_callback_t)(int event, void *user_data);

typedef struct {
    event_callback_t callback;
    void *user_data;
} EventHandler;

void register_callback(EventHandler *handler,
                       event_callback_t callback,
                       void *user_data)
{
    if (handler == NULL) {
        return;
    }

    handler->callback = callback;
    handler->user_data = user_data;
}

void trigger_event(EventHandler *handler, int event)
{
    if (handler == NULL || handler->callback == NULL) {
        return;
    }

    handler->callback(event, handler->user_data);
}

void on_event(int event, void *user_data)
{
    const char *name = (const char *)user_data;

    printf("%s receive event %d\n", name, event);
}

int main(void)
{
    EventHandler handler = {0};

    register_callback(&handler,
                      on_event,
                      "sensor");

    trigger_event(&handler, 100);

    return 0;
}
~~~

嵌入式里常见的回调场景包括 UART 接收完成、DMA 完成、GPIO 中断和驱动层事件上报。

~~~c
#include <stddef.h>
~~~

### Q17：反转单链表

需要三个指针：prev、cur、next。

~~~c
ListNode *reverse_list(ListNode *head)
{
    ListNode *prev = NULL;
    ListNode *cur = head;

    while (cur != NULL) {
        ListNode *next = cur->next;

        cur->next = prev;
        prev = cur;
        cur = next;
    }

    return prev;
}
~~~

过程：

~~~text
1 -> 2 -> 3 -> NULL

NULL <- 1    2 -> 3

NULL <- 1 <- 2    3

NULL <- 1 <- 2 <- 3
~~~

### Q18：判断链表是否有环

使用快慢指针：slow 每次走 1 步，fast 每次走 2 步。如果存在环，两者最终一定会相遇。

~~~c
bool has_cycle(const ListNode *head)
{
    const ListNode *slow = head;
    const ListNode *fast = head;

    while (fast != NULL &&
           fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast) {
            return true;
        }
    }

    return false;
}
~~~

时间复杂度 O(n)，空间复杂度 O(1)。

### Q19：找到两个单链表的相交节点

这里的“相交”指两个链表从某个节点开始共享同一批节点，而不是节点值相等。

让 A 走完自己的链表后从 B 头继续，B 走完自己的链表后从 A 头继续，两者会自动抵消长度差。

~~~c
ListNode *get_intersection_node(ListNode *head_a,
                                ListNode *head_b)
{
    ListNode *a;
    ListNode *b;

    if (head_a == NULL || head_b == NULL) {
        return NULL;
    }

    a = head_a;
    b = head_b;

    while (a != b) {
        a = (a != NULL) ? a->next : head_b;
        b = (b != NULL) ? b->next : head_a;
    }

    return a;
}
~~~

如果不相交，最终 a 和 b 都会变成 NULL。

### Q20：链表中间节点，以及删除倒数第 N 个节点

#### 找中间节点

~~~c
ListNode *middle_node(ListNode *head)
{
    ListNode *slow = head;
    ListNode *fast = head;

    while (fast != NULL &&
           fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    return slow;
}
~~~

偶数个节点时，这个实现返回后一个中间节点。

#### 删除倒数第 N 个节点

让 fast 先领先 slow N 个节点，然后一起前进。

~~~c
ListNode *remove_nth_from_end(ListNode *head,
                              size_t n)
{
    ListNode dummy = {
        .value = 0,
        .next = head
    };

    ListNode *fast = &dummy;
    ListNode *slow = &dummy;

    if (n == 0u) {
        return head;
    }

    for (size_t i = 0; i < n; ++i) {
        if (fast->next == NULL) {
            return head;
        }

        fast = fast->next;
    }

    while (fast->next != NULL) {
        fast = fast->next;
        slow = slow->next;
    }

    if (slow->next != NULL) {
        /*
         * 这里只负责摘链。
         * 如果节点来自 malloc，
         * 是否 free 由调用者的内存管理策略决定。
         */
        slow->next = slow->next->next;
    }

    return dummy.next;
}
~~~

使用 dummy 节点后，删除头节点和删除普通节点可以走同一套逻辑。

真正需要练习的不是死记代码，而是每次写完主动检查：

~~~text
NULL 指针
bit / 数组边界
整数溢出
signed / unsigned
内存重叠
宏的重复求值
~~~

嵌入式岗位尤其看重这些边界。底层代码一旦发生越界、溢出或错误的寄存器操作，最终表现往往不是简单抛出异常，而可能直接变成 HardFault、数据损坏或设备行为异常。
