# 常见传感器

在移动机器人、无人机、自动驾驶与 SLAM 系统中，传感器解决的是一个最基本的问题：**机器人如何知道自己在哪里、正在怎样运动，以及周围有什么。**

工程中最常见的四类传感器是：

- **LiDAR（激光雷达）**：直接测量距离，形成二维或三维点云；
- **Camera（视觉相机）**：获取纹理、颜色、边缘和语义信息；
- **IMU（惯性测量单元）**：高频测量三轴加速度与三轴角速度；
- **GPS/GNSS**：提供地球坐标系下的绝对位置参考。

它们不是互相替代的关系，而是非常典型的**互补关系**。

![激光、视觉、IMU 与 GNSS 传感器概览](/learning-os/image/blog/sensors/sensor-fusion-overview.svg)

> 可以先记住一句话：**LiDAR 擅长“量”，Camera 擅长“看”，IMU 擅长“感知怎么动”，GNSS 擅长“告诉你全局在哪里”。**

---

## 一、LiDAR：直接测量三维几何

激光雷达的核心优势是能够直接得到目标距离。相比相机首先得到二维像素，LiDAR 的原始观测天然带有几何尺度，因此非常适合建图、定位和障碍物检测。

### 1. TOF 飞行时间测距

最直观的激光测距方式是 **TOF（Time of Flight）**。激光发射后打到物体表面，再反射回接收器。若记录光束的往返时间为 $\Delta t$，则距离为

$
d=\frac{c\Delta t}{2},
$

其中 $c$ 为光速。之所以除以 2，是因为 $\Delta t$ 包含了“发射器到目标”和“目标回到接收器”两段距离。

![LiDAR TOF 测距与扫描方式](/learning-os/image/blog/sensors/lidar-tof-scan.svg)

### 2. 点云是怎样产生的？

一次距离测量只能得到某一个方向上的一个点。为了获得环境轮廓，需要不断改变激光束方向。

典型机械式多线 LiDAR 会：

1. 在垂直方向布置多条不同俯仰角的激光线束；
2. 整个扫描模块绕竖直轴旋转；
3. 每个方向不断进行距离测量；
4. 将大量带方向的距离点组合成一帧三维点云。

因此，点云中的每个点通常可以写成

$
\mathbf p_i=[x_i,\;y_i,\;z_i]^\mathrm T.
$

根据测得的距离 $r$、水平角 $\theta$ 和垂直角 $\phi$，理想情况下可由球坐标转换得到三维坐标。

### 3. 机械式、混合固态与固态 LiDAR

常见 LiDAR 按扫描结构可以粗略分为：

| 类型 | 扫描方式 | 特点 |
|---|---|---|
| 机械式 LiDAR | 整个扫描模块旋转 | 视场大、技术成熟，但有机械旋转部件 |
| 混合固态 LiDAR | 棱镜、转镜、MEMS 等内部扫描 | 结构更紧凑，可减少大尺寸旋转机构 |
| OPA 固态 LiDAR | 光学相控阵控制光束方向 | 无宏观机械扫描，集成度高 |
| Flash LiDAR | 一次照亮整个视场 | 类似“闪光灯 + 深度相机”，帧式获取深度 |

实际工程选型需要同时考虑视场角、量程、点频、角分辨率、成本、可靠性以及目标场景。

### 4. 为什么激光点云会发生运动畸变？

需要特别注意：**一帧点云不是同一时刻采出来的。**

假设一帧扫描需要 $100\,\mathrm{ms}$。扫描第一个点时机器人位于姿态 $T(t_k)$，扫描最后一个点时可能已经移动到了 $T(t_{k+1})$。如果直接把这些点当成同一坐标系中的同时刻观测，就会使物体出现弯曲、拉伸或错位。

![激光点云运动畸变与校正](/learning-os/image/blog/sensors/lidar-motion-distortion.svg)

典型去畸变流程是：

1. 根据扫描角度或点的时间戳确定每个点的测量时刻 $t_i$；
2. 利用 IMU、轮速计或融合里程计估计扫描周期内的位姿变化；
3. 插值得到 $T(t_i)$；
4. 将所有点统一变换到同一参考时刻，例如扫描末尾 $t_{k+1}$。

这也是为什么很多 LIO（LiDAR-Inertial Odometry）系统中，**IMU 不只是用来提高定位频率，也直接参与点云去畸变。**

## 二、Camera：从三维世界到二维像素

相机提供的信息量非常丰富。道路边缘、车道线、文字、颜色、物体类别、纹理等信息，都更适合通过视觉获取。

但相机与 LiDAR 有一个非常重要的区别：

> **相机直接测到的是像素，而不是三维距离。**

### 1. 针孔相机模型

经典相机模型可以理解为：空间点 $P(X,Y,Z)$ 经过相机光心投影到二维图像平面。

![针孔相机投影模型](/learning-os/image/blog/sensors/camera-pinhole.svg)

在理想针孔模型中，归一化平面坐标为

$
X'=\frac{X}{Z},\qquad
Y'=\frac{Y}{Z}.
$

再经过相机内参，可以得到像素坐标

$
u=f_xX'+c_x,\qquad
v=f_yY'+c_y,
$

其中：

- $f_x,f_y$：像素单位下的焦距；
- $c_x,c_y$：主点坐标；
- $(u,v)$：最终图像像素位置。

### 2. 为什么单目相机会丢失深度？

如果将 $X,Y,Z$ 同时乘上相同倍数，得到的二维投影仍然相同。因此一张普通单目图像中，同一个像素只表示一条从相机光心出发的射线，目标可能位于这条射线上的不同深度。

恢复深度通常需要额外信息，例如：

- 双目相机视差；
- RGB-D 深度传感器；
- 多帧运动；
- 已知物体尺寸；
- LiDAR 深度；
- 神经网络深度估计。

### 3. 相机畸变与标定

真实镜头并不满足完美针孔模型，还会产生径向畸变、切向畸变和镜头装配误差。因此机器人视觉系统通常先进行**相机标定**，得到内参和畸变参数，再对图像做去畸变处理。

### 4. 相机的优势与不足

**优势：** 信息密度高、语义丰富、成本较低，适合目标检测、分类、分割和视觉特征提取。

**不足：** 对强光、弱光、逆光和重复纹理敏感；单目缺少直接绝对深度；高速运动可能产生运动模糊。

## 三、IMU：高频感知“机器人怎么动”

IMU（Inertial Measurement Unit）通常包含三轴加速度计和三轴陀螺仪。

![IMU 的测量与典型误差模型](/learning-os/image/blog/sensors/imu-error-model.svg)

### 1. 加速度计与陀螺仪

加速度计可用简化模型表示为

$
\tilde{\mathbf a}=\mathbf a+\mathbf b_a+\mathbf n_a,
$

陀螺仪可用简化模型表示为

$
\tilde{\boldsymbol\omega}=\boldsymbol\omega+\mathbf b_g+\mathbf n_g.
$

其中 $\mathbf b_a,\mathbf b_g$ 是零偏，$\mathbf n_a,\mathbf n_g$ 是噪声。

### 2. 为什么 IMU 会漂移？

将角速度积分可以更新姿态，将加速度积分可以传播速度和位置。但任何很小的零偏都会被积分不断累积。

特别是姿态一旦产生误差，对重力方向的补偿也会发生错误，随后速度和位置误差往往会快速增长。

### 3. IMU 的典型误差

常见误差包括：

- **Noise**：随机测量噪声；
- **Bias**：零偏；
- **Scale factor**：尺度因数误差；
- **Axis misalignment**：轴间不正交或安装不对准；
- **Bias random walk**：零偏随机游走。

其中一部分可通过静态或多姿态标定估计，随机误差则常通过 Allan Variance 等方法进行统计建模。

### 4. IMU 为什么适合做融合？

IMU 的特点是高频、连续、不依赖环境纹理和光照，但不能长期单独稳定定位。

因此在融合系统中，它通常承担：

> **高频传播状态；Camera / LiDAR / GNSS 再不断提供相对或绝对观测来纠正漂移。**

## 四、GPS / GNSS：提供全局绝对位置

GPS 是 GNSS 的一个组成部分。更广义的 GNSS 还包括北斗、Galileo、GLONASS 等卫星导航系统。

![GPS / GNSS 全球定位原理](/learning-os/image/blog/sensors/gnss-positioning.svg)

### 1. GNSS 的基本定位思路

卫星不断广播自身轨道信息与高精度时间信息。接收机根据卫星信号传播时间，可以得到到卫星的**伪距**。

对于卫星 $i$，简化模型可写成

$
\rho_i=\|\mathbf p-\mathbf p_i\|+c\delta t+\varepsilon_i,
$

其中：

- $\mathbf p$：接收机未知位置；
- $\mathbf p_i$：卫星位置；
- $c\delta t$：接收机时钟偏差造成的距离误差；
- $\varepsilon_i$：传播和测量误差。

由于不仅要估计三维位置，还需要估计接收机钟差，所以通常至少需要四颗可用卫星进行基本三维定位。

### 2. GNSS 最大的价值：绝对位置

LiDAR、Camera 和 IMU 常构成相对定位系统，即机器人知道“相对起点移动了多少”。GNSS 则能提供经度、纬度和高度等地球坐标系下的绝对参考。

### 3. 为什么高楼附近 GNSS 会变差？

GNSS 非常依赖卫星可见性。在室内、隧道、高楼城市峡谷、树木遮挡和桥梁下方容易退化。

主要影响包括：

- 信号遮挡；
- 多路径反射；
- 电离层 / 对流层延迟；
- 卫星几何分布不理想。

因此高精度移动机器人通常不会把 GNSS 当作唯一定位来源。

## 五、四类传感器到底有什么区别？

| 传感器 | 直接观测 | 频率特点 | 最擅长 | 主要弱点 |
|---|---|---|---|---|
| LiDAR | 距离 / 点云 | 中高频 | 三维几何、建图、障碍检测 | 成本、天气、语义弱 |
| Camera | 二维像素 | 中高频 | 纹理、语义、目标识别 | 光照、尺度、深度 |
| IMU | 加速度 / 角速度 | 高频 | 短时运动传播 | 长期漂移 |
| GPS/GNSS | 全球位置相关观测 | 较低频 | 绝对定位 | 遮挡、多路径、室内不可用 |

可以用四句话快速记忆：

- Camera：**看得懂，但未必量得准**；
- LiDAR：**量得准，但不一定看得懂**；
- IMU：**短时间知道怎么动，时间一长就会漂**；
- GNSS：**知道全球位置，但局部连续性和遮挡环境不好**。

## 六、常见融合组合

### 1. Visual + IMU：VIO

Visual-Inertial Odometry 使用相机提供特征与几何约束，IMU 提供高频运动传播。它设备轻量、成本较低，在无人机、手机和 AR/VR 中非常常见。

### 2. LiDAR + IMU：LIO

LiDAR-Inertial Odometry 使用 LiDAR 的三维几何约束不断纠正 IMU 漂移。IMU 同时可用于点云运动补偿和扫描匹配初值。

### 3. LiDAR + Camera

LiDAR 提供精确三维结构，Camera 提供颜色与语义，常用于三维目标检测、语义地图与自动驾驶感知。

### 4. LiDAR / Camera / IMU + GNSS

室外大范围导航中还可以进一步加入 GNSS：

- IMU：高频运动；
- Camera / LiDAR：局部相对约束；
- GNSS：全局绝对约束。

这样既能保持短时连续定位，又能抑制长时间累计漂移。

## 七、传感器融合真正困难的地方

### 1. 时间同步

如果相机图像、LiDAR 点云和 IMU 数据实际上来自不同时间，高速运动时就会产生明显空间错位。

因此多传感器系统必须关注：

- 硬件同步；
- 精确时间戳；
- 时间偏移标定。

### 2. 外参标定

不同传感器有各自坐标系，例如 LiDAR 坐标系、Camera 坐标系、IMU 坐标系和 Body 坐标系。系统必须准确知道它们之间的刚体变换。

外参稍有错误，在远距离目标和高速运动中就会产生明显误差。

### 3. 坐标系管理

机器人中经常同时存在：

- 世界坐标系；
- 地图坐标系；
- 里程计坐标系；
- Body 坐标系；
- Camera / LiDAR / IMU 坐标系；
- GNSS 地理坐标系。

工程上非常实用的一条经验是：**先把坐标系和变换关系画清楚，再开始写融合代码。**

### 4. 误差模型

融合算法并不是简单求平均。不同传感器的残差形式不同：

- Camera：重投影误差；
- LiDAR：点到面 / 点到线距离误差；
- IMU：噪声、Bias 与预积分误差；
- GNSS：位置协方差、多路径和卫星几何误差。

EKF、ESKF、因子图和非线性优化本质上都要回答：**当前这条观测应该相信多少？**

---

## 八、从传感器到 SLAM 的整体链路

一个典型机器人定位系统可以理解为：

**LiDAR 点云 / Camera 图像 / IMU 惯性数据 / GNSS 全局观测 → 状态估计与多传感器融合 → 位姿 → 建图、感知与路径规划。**

最终状态往往不仅包含位置与姿态，还包括速度和 IMU Bias，例如

$
\mathbf x=
[\mathbf p,\;\mathbf v,\;\mathbf R,\;\mathbf b_a,\;\mathbf b_g].
$

---

## 九、总结

四类传感器可以用四句话记住：

- **LiDAR：测距离，获得三维几何；**
- **Camera：看环境，获得纹理和语义；**
- **IMU：测运动，高频但会漂移；**
- **GPS/GNSS：给全局位置，但依赖卫星环境。**

真实机器人中，没有哪一种传感器在所有场景都最好。更合理的系统设计是根据每种传感器的**观测特性、时间特性与误差模型**，把它们组合成一个互相补偿的定位与感知系统。

理解这四类传感器之后，可以继续学习：

1. 坐标系与刚体变换；
2. 相机内外参标定；
3. IMU 预积分与误差传播；
4. LiDAR 点云配准与运动去畸变；
5. EKF / ESKF；
6. 因子图与非线性优化；
7. VIO、LIO 与 GNSS 融合定位。
