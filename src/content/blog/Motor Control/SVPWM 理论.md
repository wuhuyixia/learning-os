# 1\. SVPWM 在 FOC 中的作用

![SVPWM 在 FOC 中的电压变换示意图](/learning-os/image/svpwm/image%2015.png)

![Park 逆变换与 SVPWM 输入电压矢量](/learning-os/image/svpwm/image%206.png)

SPWM 是通过 Clark 逆变换将 $V_α$、$V_β$ 转换成三相上的正弦波电压，而 SVPWM 是通过更复杂的复杂方法，将其转换成三相上的**马鞍波**电压。



将**控制器计算出的** $V_d$、$V_q$ 与 **反馈的电角度** $θ$ 通过 Park 逆变换，可将旋转坐标系 `d-q` 下的电压指令转换成**静止坐标系 ****`α-β`**** 下的目标电压矢量分量**，再送入 SVPWM 进行**调制**。



在 FOC 中，通常在 `d-q` 坐标系下进行电流控制，因为此时交流量可变为近似直流量，便于 PI 调节。但**在输出到逆变器之前，必须将电压指令变回静止坐标系**，因为 **SVPWM 的扇区判断、电压矢量合成以及三相桥臂占空比计算，都是在定子静止坐标系下完成的**。



# 2\. 什么是 SVPWM？

SVPWM（Space Vector Pulse Width Modulation，空间矢量脉宽调制）是一种广泛应用于电机控制（尤其是 BLDC 和 PMSM）的**调制**方法。SVPWM 的核心思想是**通过空间矢量的方式来控制逆变器的开关状态**，从而有效地提高电机驱动系统的效率和性能。



- **更高的直流电源利用率**：SVPWM 比 SPWM 更能充分利用直流电源的电压，因此能够提供更高的输出电压。

- **减少谐波**：SVPWM 通过**选择合适的矢量和开关时序**，能够有效地减少谐波，使得电机运行更加平稳，降低电磁干扰（EMI）和噪声。

- **更高效的控制**：SVPWM 能够提供更平稳的电流波形，减少电流波动和失真，进而提高电机的效率和控制精度。

## 3\.1 基本电压矢量

矢量六边形被八个基本电压矢量分为六个扇区，每个基本电压矢量都是由**三相逆变器三个桥臂的开关状态组合**决定的。



**规定**：

- 1 表示该相上管导通

- 0 表示该相下管导通



![基本电压矢量与逆变器开关状态](/learning-os/image/svpwm/image%207.png)



# 4\. 如何**合成六边形内任意方向、任意大小的电压空间矢量？**

先**确定目标电压空间矢量所在扇区**，用**所在扇区的两个相邻基本矢量，加上零矢量**，根据**作用时间加权平均**，就能合成六边形内任意方向、任意大小的目标电压空间矢量。



## **4\.1 时间加权平均**

在一个 PWM 周期内，目标电压矢量 $V_{ref}$ 可由所在扇区的两个 相邻基本矢量 和 零矢量 按作用时间加权平均合成。



**例**：

若目标矢量 $V_{ref}$ 位于 I 区，则选取 I 区的相邻有效矢量 $U_4$ 、$U_6$ ，以及零矢量 $U_0$ 。



在一个 PWM 周期 $T_s$ 内：

- $U_4$ 的作用时间为 $T_1$

- $U_6$ 的作用时间为 $T_2$

- $U_0$ 的作用时间为 $T_0$



则满足：

$T_1 + T_2 + T_0 = T_s$



基本矢量 $U_4$、$U_6$、$U_0$ 按作用时间折算后的等效作用量：

- $V_1 = \frac{T_1}{T_s}U_4$

- $V_2 = \frac{T_2}{T_s}U_6$

- $V_0 = \frac{T_0}{T_s}U_0$



那么目标电压矢量 $V_{ref}$ 可表示为：

$V_{ref} = V_1 + V_2 + V_0$



### 4\.1\.1 大小与方向

目标矢量的方向主要由两个相邻非零基本矢量的作用时间比例 $\frac{T_1}{T_2}$ 决定；大小主要由总有效作用时间与周期**之比** $\frac{T_1 + T_2}{T_s}$ 决定。



## 4\.2 扇区判断

通过**目标矢量的角度**来判断在哪个扇区。

### 4\.2\.3 推导

由于三相绕组每个相之间相差 120°，所以六个基础矢量相差 60° 。



- **第 I 扇区（0 \~ 60°）：**

    $V_α > 0 $，$V_β > 0 $

    $\frac{V_β}{V_α} < \sqrt3$  `->`  $\sqrt3V_α - V_β > 0$



- **第 II 扇区（60 \~ 120°）：**

    - **① 60 \~ 90°**：

        $V_α > 0 $，$V_β > 0 $

        $\frac{V_β}{V_α} > \sqrt3$  `->`  $\sqrt3V_α - V_β ＜ 0$



    - **② 90 \~ 120°**：

        $V_α < 0 $，$V_β > 0 $

        $\frac{Vu_β}{V_α} < -\sqrt3$  `->` $-\sqrt3V_α - V_β < 0$



- **第 III 扇区（120 \~ 180°）：**

    $V_α < 0 $，$V_β > 0 $

    $\frac{V_β}{V_α} > -\sqrt3$  `->`  $-\sqrt3V_α - V_β > 0$



- **第 IV 扇区（180 \~ 240°）：**

    $V_α < 0 $，$V_β < 0 $

    $\frac{V_β}{V_α} < \sqrt3$  `->`  $\sqrt3V_α - V_β < 0$



- **第 V 扇区（240 \~ 300°）：**

    - **① 240 \~ 270°**：

        $V_α < 0 $，$V_β < 0 $

        $\frac{V_β}{V_α} > \sqrt3$  `->`  $\sqrt3V_α - V_β > 0$



    - **② 270 \~ 300°**：

        $V_α > 0 $，$V_β < 0 $

        $\frac{V_β}{V_α} < -\sqrt3$  `->` $-\sqrt3V_α - V_β > 0$



- **第 VI 扇区（300 \~ 360°）：**

    $V_α > 0 $，$V_β < 0 $

    $\frac{V_β}{V_α} > -\sqrt3$  `->`  $-\sqrt3V_α - V_β < 0$



将 $V_β$、$(\sqrt3V_α - V_β)$、$(-\sqrt3V_α - V_β)$ 三项提取出来，设置三个 Bit ，若某个项大于 0，则对应位置 1，反之置 0。

|**扇区**|$(-\sqrt3V_α - V_β)$|$(\sqrt3V_α - V_β)$|$V_β$|结果        |
|---|---|---|---|---|
|I|0|1|1|3|
|II ①|0|0|1|1<br>|
|II ②|0|0|1||
|III|1|0|1|5|
|IV|1|0|0|4|
|V ①|1|1|0|6<br>|
|V ②|1|1|0||
|VI|0|1|0|2|



## 4\.3 作用顺序

通过前面的扇区判断，我们已经能够确定目标矢量 $V_{ref}$ 所在的扇区，以及该扇区的基本矢量。现在需要考虑，**如何生成基本矢量，并通过基本矢量生成目标矢量 **$V_{ref}$** ？**



### 4\.3\.1 如何在**极短的控制周期**内生成**基本矢量？**

在 **PWM 周期内部**生成基本矢量。一般 MCU 的定时器有多个 PWM 通道，所以三相的 PWM 可以共用一个定时器的计数值。



以扇区 I 为例：

![SVPWM 有效矢量作用时间](/learning-os/image/svpwm/image%208.png)

小于计数值，该相状态为 0，反之为 1

|三相状态|A|B|C|补充|
|---|---|---|---|---|
|时间段 1|0|0|0|生成零矢量 $U_0$ |
|时间段 2|1|0|0|生成基本矢量 $U_4$ |
|时间段 3|1|1|0|生成基本矢量 $U_6$  |
|时间段4|1|1|1|生成零矢量 $U_7$ |

![SVPWM 对称开关序列](/learning-os/image/svpwm/image%204.png)

我们将基本矢量的生成放在了 PWM 周期内部，通过不同通道之间的比较值，实现在极短周期内生成基本矢量。



### 4\.3\.2 如何在生成基本矢量与合成目标矢量的过程中，尽可能**降低谐波？**

由图：`扇区 I 的基本矢量合成` 可得，**在一个 PWM 周期内，每次基本矢量的变换，都只改变了一相的状态**，因为 MOS 的开关比较少，所以谐波就会更低。



但是，当第二个周期到来时，三相的状态会从 `111` 变为 `000`：

![扇区一的开关序列](/learning-os/image/svpwm/image%2013.png)



若采用边沿对齐方式，相邻 PWM 周期的边界处可能出现多个桥臂同时翻转，会增大开关冲击和谐波。因此通常采用中央对齐模式，使开关序列关于周期中心对称。



因此，我们将定时器的计数设置为 **中央对齐模式 **：计数值从 0 累加到最大计数值后，再累减到 0。

![三相 PWM 占空比生成](/learning-os/image/svpwm/image%205.png)

对应的三相状态波形图：镜像

![SVPWM 作用时间计算](/learning-os/image/svpwm/image%2011.png)

## 4\.4 作用时间

**规定**：

- 零矢量的作用时间为 $T_0$

- 第一个相邻非零基本矢量 按作用时间折算后的**等效作用量**为 $V_1$，该基本矢量的作用时间为 $T_1$

- 第二个相邻非零基本矢量 按作用时间折算后的等效作用量为 $V_2$，该基本矢量的作用时间为 $T_2$



### 4\.4\.1 扇区作用时间推导

对于 SVPWM，已知目标电压矢量 $V_{ref}$ **在静止坐标系** `α-β` **下的分量** $V_α$ 、 $V_β$：

- 根据 $V_α$ 、 $V_β$ 确定 $V_{ref}$ 所在的扇区

- 选取该扇区内的两个相邻非零基本矢量** **$U_x$、$U_y$

- **将 **$V_{ref}$** 从 **`α-β` **分解到该扇区的两个相邻非零基本矢量方向上**，并计算它们在一个 PWM 周期内按作用时间折算后的等效作用量 $V_1$ 、$V_2$。



- $V_{ref}$** 落在 I 扇区**：

    1. 计算 $V_1$ 、$V_2$：

        选取相邻非零基本矢量为 $U_4$、$U_6$，其按作用时间折算后的等效作用量 $V_1$、$V_2$,由**七段式作用顺序**知，$V_1$ 对应 $U_4$，$V_2$ 对应 $U_6$ 。



        - 将 $V_1$ 、$V_2$ 分解到** **`α-β` 坐标系：

            $V_1 + V_2 cos60° = V_α$

            $V_2 sin60° = V_β$

        - **反解 **$V_1$** 、**$V_2$：

            $V_1 = V_α - \frac{1}{2}V_2 = V_α - \frac{V_β}{\sqrt3}$

            $V_2 = \frac{V_β}{sin60°} = \frac{2V_β}{\sqrt3}$



    2. 计算 $T_1$ 、$T_2$：

        - 因为：

            基本矢量模长 $|U|=\frac{2}{3}U_{dc}$

        - 所以有：

            $V_1 = \frac{T_1}{T_s}\cdot \frac{2}{3}U_{dc}$

            $V_2 = \frac{T_2}{T_s}\cdot \frac{2}{3}U_{dc}$

        - 反解 $T_1$ 、$T_2$、$T_0$：

            $T_1 = \frac{3T_s}{2U_{dc}} \cdot V_1 = (-\frac{\sqrt3T_s}{U_{dc}}) \cdot (-\frac{\sqrt3}{2}V_α + \frac{1}{2}V_β)$

            $T_2 = \frac{3T_s}{2U_{dc}} \cdot V_2 = (\frac{\sqrt3T_s}{U_{dc}}) \cdot V_β$

            $T_0 = T_s - T_1 - T_2$



- $V_{ref}$** 落在 II 扇区**：

    $T_1 = (\frac{\sqrt3T_s}{U_{dc}}) \cdot (-\frac{\sqrt3}{2}V_α + \frac{1}{2}V_β)$

    $T_2 = (\frac{\sqrt3T_s}{U_{dc}}) \cdot (\frac{\sqrt3}{2}V_α + \frac{1}{2}V_β)$



- $V_{ref}$** 落在 III 扇区**：

    $T_1 = (\frac{\sqrt3T_s}{U_{dc}}) \cdot V_β$

    $T_2 = (-\frac{\sqrt3T_s}{U_{dc}}) \cdot (\frac{\sqrt3}{2}V_α + \frac{1}{2}V_β)$



- $V_{ref}$** 落在 IV 扇区**：

    $T_1 = (-\frac{\sqrt3T_s}{U_{dc}}) \cdot V_β$

    $T_2 = (\frac{\sqrt3T_s}{U_{dc}}) \cdot (-\frac{\sqrt3}{2}V_α + \frac{1}{2}V_β)$



- $V_{ref}$** 落在 V 扇区**：

    $T_1 = (-\frac{\sqrt3T_s}{U_{dc}}) \cdot (\frac{\sqrt3}{2}V_α + \frac{1}{2}V_β)$

    $T_2 = (-\frac{\sqrt3T_s}{U_{dc}}) \cdot (-\frac{\sqrt3}{2}V_α + \frac{1}{2}V_β)$



- $V_{ref}$** 落在 VI 扇区**：

    $T_1 = (\frac{\sqrt3T_s}{U_{dc}}) \cdot (\frac{\sqrt3}{2}V_α + \frac{1}{2}V_β)$

    $T_2 = (-\frac{\sqrt3T_s}{U_{dc}}) \cdot V_β$



#### 4\.4\.1\.1 统一

令：

- $X = \frac{\sqrt3T_s}{U_{dc}} \cdot V_β$

- $Y = \frac{\sqrt3T_s}{U_{dc}} \cdot (\frac{\sqrt3}{2}V_α + \frac{1}{2}V_β)$

- $Z = \frac{\sqrt3T_s}{U_{dc}} \cdot (-\frac{\sqrt3}{2}V_α + \frac{1}{2}V_β)$



有：

|扇区|$T_1$|$T_2$|
|---|---|---|
|I|$-Z$|$X$|
|II|$Z$|$Y$|
|III|$X$|$-Y$|
|IV|$-X$|$Z$|
|V|$Y$|$-Z$|
|VI|$Y$|$-X$|



# 5\. 如何转换成 PWM 比较值？

这一步我们实际在做的是把**一个PWM周期内各基本矢量的作用时间** ，转换成**三相的归一化 PWM 比较值/占空比命令 **$t_A、t_B、t_C$。



再由：

- CCR\_A = tA \* ARR

- CCR\_B = tB \* ARR

- CCR\_C = tC \* ARR

写入定时器 CCR 寄存器。



$t_A、t_B、t_C$ 可按当前扇区** 最小相 = T0/2，中间相 = T0/2 \+ 第一个非零基本矢量作用时间，最大相 = T0/2 \+ 两个非零基本矢量作用时间 **来构造，**中心对齐定时器**再根据这组比较值把脉冲自动展开为关于周期中心对称的波形。



以 扇区 II 为例：

![SVPWM 饱和区域](/learning-os/image/svpwm/image%209.png)

![SVPWM 与 SPWM 调制范围对比](/learning-os/image/svpwm/image%2014.png)

```C
case SECTOR_2:
{
    float T2 = Z;
    float T6 = Y;

    // 用 T0/2 作为零矢量公共偏置，构造三相归一化比较值
    // 最小相（T0/2）
    tC = 0.5f * (1.0f - T6 - T2); // 1 表示 PWM 周期已归一化
    // 中间相（T0/2 + T6）
    tA = tC + T6;
    // 最大相（T0/2 + T6 + T2）
    tB = tA + T2;

    break;
}

```
