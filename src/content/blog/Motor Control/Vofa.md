# VOFA+ 上位机简介与使用

VOFA+ 是一款常用的串口调试与数据可视化工具，可以接收单片机发送的数据，并以波形、数值等形式显示，适合观察速度、电流、位置和 PWM 等变量。

## 1. 基本使用

1. 使用 USB 转串口工具连接开发板。
2. 打开 VOFA+，选择正确的串口号和波特率。
3. 选择数据协议，点击开始接收。
4. 在波形窗口中选择需要观察的通道，并设置名称和单位。

常用协议有：

- **FireWater**：文本协议，调试简单，适合低速数据观察。
- **JustFloat**：二进制浮点协议，数据量较大时效率更高。

## 2. FireWater 示例

使用 FireWater 协议时，可以让单片机按通道顺序发送数据，并使用分号结束一帧：

```c
printf("%.3f,%.3f,%.3f;\r\n", speed, current, duty);
```

上例依次发送速度、电流和 PWM 占空比三个通道。VOFA+ 接收到数据后即可绘制实时曲线。

## 3. 使用建议

- 发送格式必须与 VOFA+ 当前选择的协议一致。
- 检查串口号、波特率和数据线是否正确。
- 不要在高速控制中频繁使用阻塞式 `printf`，必要时使用 DMA 或降低发送频率。
- 调试电机控制时，可以优先观察目标值、反馈值和控制输出，便于判断误差来源。
