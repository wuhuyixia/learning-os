### First Fit、Best Fit 与 Worst Fit 的区别

当空闲链表中同时存在多个可用块时，分配器需要决定“从哪一块空闲内存中完成本次申请”。三种经典策略的核心区别如下：

- **First Fit（首次适配）**：从链表头开始向后查找，遇到第一个足够大的空闲块就立即分配。实现最简单、查找通常最快，但长期运行后容易在链表前部留下较多小碎片。
- **Best Fit（最佳适配）**：遍历所有空闲块，选择“能够满足申请且大小最小”的那一块。单次分配后剩余空间较少，但查找开销更大，并且容易留下很多很小、难以再次利用的碎片。
- **Worst Fit（最差适配）**：遍历所有空闲块，优先选择当前最大的空闲块。它希望分割后仍保留较大的剩余块，但会持续消耗最大的连续空闲空间。

上方动画使用完全相同的初始空闲块和申请序列同步播放三种策略，因此可以直接观察：**First Fit 更关注速度，Best Fit 更关注单次贴合程度，Worst Fit 更关注保留较大的剩余块。**

下面给出三种策略的核心实现。

```c
// First Fit：找到第一个足够大的空闲块
void* first_fit_malloc(size_t size) {
    block_header_t* current = free_list;

    while (current != NULL) {
        if (current->is_free && current->size >= size) {
            current->is_free = 0;
            return (void*)((uint8_t*)current + sizeof(block_header_t));
        }
        current = current->next;
    }

    return NULL;
}
```

```c
// Best Fit：找到最小但仍足够大的空闲块
void* best_fit_malloc(size_t size) {
    block_header_t* current = free_list;
    block_header_t* best = NULL;
    size_t best_size = SIZE_MAX;

    while (current != NULL) {
        if (current->is_free && current->size >= size && current->size < best_size) {
            best = current;
            best_size = current->size;
        }
        current = current->next;
    }

    if (best != NULL) {
        best->is_free = 0;
        return (void*)((uint8_t*)best + sizeof(block_header_t));
    }

    return NULL;
}
```

```c
// Worst Fit：找到最大的空闲块
void* worst_fit_malloc(size_t size) {
    block_header_t* current = free_list;
    block_header_t* worst = NULL;
    size_t worst_size = 0;

    while (current != NULL) {
        if (current->is_free && current->size >= size && current->size > worst_size) {
            worst = current;
            worst_size = current->size;
        }
        current = current->next;
    }

    if (worst != NULL) {
        worst->is_free = 0;
        return (void*)((uint8_t*)worst + sizeof(block_header_t));
    }

    return NULL;
}
```

> 这里为了突出“如何选择空闲块”，代码省略了真实分配器中的块分裂、对齐、元数据维护以及相邻空闲块合并等细节。

## 5. 栈与堆的核心区别

栈主要用于函数调用、局部变量和返回地址等临时数据，通常由编译器和处理器自动管理；堆用于运行时动态内存分配，需要通过 `malloc` / `free` 等接口显式申请和释放。

栈通常遵循后进先出（LIFO）的使用方式，空间释放具有明显的栈帧边界；堆的分配顺序更加自由，频繁申请和释放后可能出现不连续的空闲区域，从而形成外部碎片。
