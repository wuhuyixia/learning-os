# 指针

指针本质上是一个**保存内存地址的变量**。普通变量保存数据，指针变量保存“数据在哪里”。

例如：

```c
int a = 10;
int *p = &a;
```

可以理解为：

```text
p ─────→ a
         10
```

其中：

- `&a`：取得变量 `a` 的地址；
- `p`：保存 `a` 的地址；
- `*p`：访问该地址中的数据。

因此：

```c
*p = 20;
```

等价于通过地址修改 `a`：

```c
a = 20;
```

## 1. 指针函数

如果一个函数的返回值是指针，例如：

```c
int *get_data(void);
```

那么它称为**指针函数**，即“返回指针的函数”。

一个需要特别注意的问题是：**不能安全地返回普通局部变量的地址**。

例如：

```c
int *func(void)
{
    int a = 10;
    return &a;
}
```

`a` 位于 `func()` 的栈帧中。当函数返回后，`a` 的生命周期结束，返回出去的地址就变成了悬空地址。

下面的动画演示两个函数先后复用同一块栈空间时，为什么两个指针可能出现相同地址，以及为什么“地址还在”并不代表对象仍然有效。

## 2. 函数指针

函数本身也存放在程序的代码区，因此函数同样具有入口地址。**函数指针就是专门用来保存函数入口地址的指针。**

例如有一个函数：

```c
int func(int a)
{
    int b = 10;
    int c = a * b;
    return c;
}
```

如果要定义一个指针，使它能够指向 `func()`，可以写成：

```c
int (*pa)(int) = NULL;
```

这条声明可以从变量名 `pa` 开始理解：

```text
(*pa)        → pa 是一个指针
(*pa)(int)   → pa 指向一个参数为 int 的函数
int (*pa)(int)
             → 这个函数的返回值为 int
```

因此：

```c
int (*pa)(int);
```

表示：

> `pa` 是一个函数指针，它可以指向“接收一个 `int` 参数并返回 `int`”的函数。

### 为什么必须写括号

下面两种写法完全不同：

```c
int *pa(int);      // 指针函数
int (*pa)(int);    // 函数指针
```

原因是 `()` 的优先级高于 `*`。

```text
int *pa(int)
     └─ pa(int) 先结合
        → pa 是函数
        → 返回 int *

int (*pa)(int)
    └─ (*pa) 被括号包住
       → pa 先是指针
       → 指向函数
```

所以可以直接记住：

```text
指针函数：函数 → 返回指针
函数指针：指针 → 指向函数
```

### 函数地址与赋值

函数名在大多数表达式中会转换为函数指针，因此可以直接写：

```c
pa = func;
```

也可以写成：

```c
pa = &func;
```

此时可以理解为：

```text
Code / Flash

0x08000100
┌────────────────┐
│ func(int a)    │
│ return a * 10; │
└────────────────┘
        ▲
        │ 函数入口地址
        │
┌───────┴───────┐
│ pa            │
│ 0x08000100    │
└───────────────┘
```

### 通过函数指针调用函数

赋值之后，可以直接通过 `pa()` 调用：

```c
#include <stdio.h>

int func(int a)
{
    int b = 10;
    return a * b;
}

int main(void)
{
    int (*pa)(int) = NULL;

    pa = func;

    int result1 = func(10);
    int result2 = pa(10);
    int result3 = (*pa)(10);

    printf("func(10) = %d\n", result1);
    printf("pa(10)   = %d\n", result2);
    printf("(*pa)(10)= %d\n", result3);

    return 0;
}
```

三种调用方式最终执行的都是同一个 `func()`：

```text
func(10)
   │
   ├──────────────┐
   │              │
pa(10)         (*pa)(10)
   │              │
   └──────┬───────┘
          ▼
      func(int a)
          ▼
       return 100
```

其中更常见的写法是：

```c
pa(10);
```

### 使用 typedef 简化声明

复杂函数指针声明通常可以使用 `typedef` 简化：

```c
typedef int (*FuncPtr)(int);

FuncPtr pa = func;
```

此时 `FuncPtr` 表示：

```text
指向“参数为 int、返回值为 int”的函数的指针类型
```

函数指针在嵌入式开发中非常常见，典型用途包括：**回调函数、状态机、驱动接口、命令分发表和中断处理接口**。

## 3. 悬空指针

悬空指针（Dangling Pointer）指的是：指针仍然保存一个地址，但该地址对应的对象已经失效。

典型情况包括：

- 返回局部变量地址；
- `free()` 后继续使用旧指针；
- 对象生命周期结束后仍然保存其地址。

正确做法是让返回对象具有足够长的生命周期。例如：

```c
int *func(void)
{
    static int a = 10;
    return &a;
}
```

`static` 局部变量不会随着函数返回而销毁，因此返回它的地址是有效的。

## 4. 一句话理解

```text
普通变量：保存数据
指针变量：保存地址
*p：访问地址中的数据
```

指针函数与函数指针最容易混淆，可以这样区分：

```text
int *func(void);
    ↓
函数 → 返回 int *

int (*pa)(int);
     ↓
指针 → 指向函数
       参数：int
       返回：int
```

真正需要记住的是：**先找到变量名，再看它首先与 `()` 结合还是与 `*` 结合。**
