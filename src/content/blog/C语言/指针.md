# 指针

指针本质上是一个**保存内存地址的变量**。普通变量保存数据，指针变量保存“数据在哪里”。

例如：

```c
int a = 10;
int *p = &a;
```

可以理解为：

```text
p ─────→ a
         10
```

其中：

- `&a`：取得变量 `a` 的地址；
- `p`：保存 `a` 的地址；
- `*p`：访问该地址中的数据。

因此：

```c
*p = 20;
```

等价于通过地址修改 `a`：

```c
a = 20;
```

## 1. 指针函数

如果一个函数的返回值是指针，例如：

```c
int *get_data(void);
```

那么它称为**指针函数**，即“返回指针的函数”。

一个需要特别注意的问题是：**不能安全地返回普通局部变量的地址**。

例如：

```c
int *func(void)
{
    int a = 10;
    return &a;
}
```

`a` 位于 `func()` 的栈帧中。当函数返回后，`a` 的生命周期结束，返回出去的地址就变成了悬空地址。

## 2. 悬空指针

悬空指针（Dangling Pointer）指的是：指针仍然保存一个地址，但该地址对应的对象已经失效。

典型情况包括：

- 返回局部变量地址；
- `free()` 后继续使用旧指针；
- 对象生命周期结束后仍然保存其地址。

正确做法是让返回对象具有足够长的生命周期。例如：

```c
int *func(void)
{
    static int a = 10;
    return &a;
}
```

`static` 局部变量不会随着函数返回而销毁，因此返回它的地址是有效的。

## 3. 一句话理解

```text
普通变量：保存数据
指针变量：保存地址
*p：访问地址中的数据
```

而对于指针函数：

```text
函数 → 返回地址 → 指针接收
```

真正需要记住的是：**地址值存在，不等于这个地址所对应的对象仍然有效。**
