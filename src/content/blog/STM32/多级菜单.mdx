## 1. 多级菜单设计

在嵌入式人机交互系统中，如果菜单数量较多，将所有菜单项一次性显示在屏幕上会导致界面拥挤。常见做法是采用横向滚动菜单：当前菜单位于中央，两侧保留相邻菜单，通过按键、编码器、触摸或滚轮完成切换。

这种结构非常适合抽象成双向循环链表：每个菜单节点都拥有 `prev` 与 `next` 指针，子菜单则通过 `child` 与 `parent` 建立层级关系。

## 3. 双向循环链表结构

假设当前节点为 `设置`，则链表关系可以理解为：

```text
控制 ← 设置 → 时间
 ↑              ↓
 └──────────────┘
```

在 STM32 工程中，可以使用如下结构体描述菜单节点：

```c
typedef struct MenuNode
{
    const char *name;

    struct MenuNode *prev;
    struct MenuNode *next;

    struct MenuNode *parent;
    struct MenuNode *child;

    void (*callback)(void);

} MenuNode_t;
```

其中：

- `prev` 指向前一个菜单；
- `next` 指向后一个菜单；
- `child` 指向下一级菜单；
- `parent` 用于返回上一级；
- `callback` 指向当前菜单对应的功能函数。

## 4. 先理解普通单链表的基本操作

多级菜单本质上是在链表基础上继续增加 `prev`、`child`、`parent` 等关系，因此先把普通单链表的几个核心动作弄清楚会更容易理解菜单节点是怎么变化的。

下面把节点定义、插入、删除、反转、遍历打印和主函数演示放在一个完整代码示例里，不拆成多个零散代码块：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node
{
    int data;
    struct Node *next;
} Node_t;

static Node_t *head = NULL;

/* 头插法：新节点始终插在链表最前面 */
void Insert(int x)
{
    Node_t *newNode = (Node_t *)malloc(sizeof(Node_t));
    if (newNode == NULL)
        return;

    newNode->data = x;
    newNode->next = head;
    head = newNode;
}

/* 删除第一个值等于 x 的节点 */
void Delete(int x)
{
    Node_t *current = head;
    Node_t *prev = NULL;

    while (current != NULL)
    {
        if (current->data == x)
        {
            if (prev == NULL)
                head = current->next;
            else
                prev->next = current->next;

            free(current);
            return;
        }

        prev = current;
        current = current->next;
    }
}

/* 原地反转链表 */
void Reverse(void)
{
    Node_t *prev = NULL;
    Node_t *current = head;
    Node_t *next = NULL;

    while (current != NULL)
    {
        next = current->next;
        current->next = prev;
        prev = current;
        current = next;
    }

    head = prev;
}

/* 遍历打印 */
void Print(void)
{
    Node_t *temp = head;

    printf("List is: ");
    while (temp != NULL)
    {
        printf("%d ", temp->data);
        temp = temp->next;
    }
    printf("\n");
}

int main(void)
{
    int n, i, x;

    printf("How many numbers?\n");
    scanf("%d", &n);

    for (i = 0; i < n; i++)
    {
        printf("Enter the number: ");
        scanf("%d", &x);

        Insert(x);
        Print();
    }

    printf("Delete one value: ");
    scanf("%d", &x);
    Delete(x);
    Print();

    Reverse();
    printf("After reverse: ");
    Print();

    return 0;
}
```

这个示例和你截图里的思路一致：`head` 一开始为 `NULL`，每次输入一个数字后调用 `Insert(x)`，然后通过 `Print()` 从 `head` 开始一直沿着 `next` 指针遍历到 `NULL`。

需要特别注意的是，这里的 `Insert()` 使用的是**头插法**。例如依次输入 `10、20、30`，链表会变成：

```text
head → 30 → 20 → 10 → NULL
```

也就是说，打印顺序和输入顺序相反。如果希望保持输入顺序，则应该改用尾插法。

### 插入、删除、反转究竟改了什么

链表操作真正变化的并不是节点本身，而是节点之间的 `next` 指向关系。

<LinkedListOperationsRoughDemo />

对于插入，核心是先让新节点接住后半段链表，再让前一个节点指向它；对于删除，核心是让前驱节点直接越过目标节点；对于反转，则是依次把每个节点原本向后的 `next` 指针改成指向前一个节点。

反转过程可以简化理解成三个临时指针：

```text
prev      current      next
 ↓           ↓           ↓
NULL   →    10    →      20    → 30 → NULL
```

每轮循环都做三件事：先保存 `current->next`，再执行 `current->next = prev`，最后让 `prev` 和 `current` 一起向前推进。直到 `current == NULL`，此时 `prev` 就是新的头节点，因此最后执行 `head = prev`。

## 5. 菜单滚动

把普通链表理解清楚后，菜单滚动就很好理解了。菜单节点只是把单链表里的 `next` 扩展成了 `prev / next / child / parent` 四种关系。

```c
void MenuMoveRight(void)
{
    if (current_menu->next != NULL)
        current_menu = current_menu->next;
}

void MenuMoveLeft(void)
{
    if (current_menu->prev != NULL)
        current_menu = current_menu->prev;
}

void MenuEnter(void)
{
    if (current_menu->child != NULL)
        current_menu = current_menu->child;
}

void MenuBack(void)
{
    if (current_menu->parent != NULL)
        current_menu = current_menu->parent;
}
```

因此菜单显示逻辑与菜单数据结构可以完全解耦。显示层只需要读取 `current_menu` 以及其前后节点，而按键、旋钮或触摸事件只负责修改当前节点。

## 6. 为什么使用双向循环链表

相比普通数组，双向循环链表更适合层级菜单和动态菜单：

1. 左右切换不需要计算边界，尾节点的 `next` 可以直接指回头节点；
2. 菜单项可以动态插入或删除；
3. 父子菜单天然适合指针关系管理；
4. UI 层无需关心菜单总数量；
5. 可以方便地为每个节点绑定独立回调函数。

## 7. 与状态机结合

实际嵌入式项目中，菜单系统通常还会与有限状态机结合。例如可以定义：

```c
typedef enum
{
    MENU_IDLE,
    MENU_MOVE_LEFT,
    MENU_MOVE_RIGHT,
    MENU_ENTER,
    MENU_BACK,
    MENU_EXECUTE
} MenuState_t;
```

按键扫描、编码器或触摸驱动只负责产生事件，菜单状态机根据事件修改 `current_menu`，最后由 OLED、LCD 或 TFT 显示函数统一刷新界面。

这种设计可以将输入层、菜单逻辑层与显示层拆开，使后续增加新的输入设备或新的屏幕驱动时不需要重写整个菜单系统。
