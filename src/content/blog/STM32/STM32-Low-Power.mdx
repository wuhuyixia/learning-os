# STM32 低功耗基础：先看懂电源域、VDDA、VREF 与 VBAT

学习 STM32 低功耗之前，先要看懂芯片内部**哪些模块由哪一路电源供电**。

因为进入 Sleep、Stop、Standby 等低功耗模式，本质上就是：

> **让不需要工作的时钟、电路或电源域停下来，只保留必须继续工作的部分。**

所以第一步先把 STM32 的供电结构理清楚。

> 本文先整理电源域和相关引脚。低功耗模式、RTC 唤醒、外部中断唤醒以及各模式功耗对比，后续继续补充。

## 1. STM32 内部不是只有一路电源

可以先把芯片内部理解成四个主要区域：

<MermaidDiagram
  title="STM32 主要电源域"
  chart={`flowchart LR
    VDD[VDD\n数字电源] --> REG[内部电压调节器]
    REG --> CORE[约 1.8V 核心供电域\nCPU 内核 / 存储器 / 数字外设]

    VDD --> IO[VDD 供电域\nI/O 电路 / 待机电路 / 电压调节器]

    VDDA[VDDA\n模拟电源] --> ANA[VDDA 供电域\nADC / DAC / 温度传感器\n复位模块 / PLL]

    VBAT[VBAT\n后备电源] --> BACKUP[后备供电域\nLSE 32.768kHz\nRTC / 后备寄存器 / BDCR]`}
/>

最容易混淆的是：

```text
VDD   → 数字部分主要电源
VDDA  → 模拟部分主要电源
VBAT  → 后备域电源
VSS   → 数字地
VSSA  → 模拟地
```

不同 STM32 系列的内部结构和允许电压范围会有差异，实际设计时应以对应芯片的数据手册为准。

## 2. VDD：数字部分的主要电源

`VDD` 是 STM32 的数字电源输入。

图示器件中，VDD 的供电范围为：

```text
2.0 V ~ 3.6 V
```

VDD 主要给下面这些部分供电：

- I/O 电路；
- 待机相关电路；
- 内部电压调节器。

其中很重要的一点是：

> **CPU 内核通常并不是直接工作在 VDD 电压上。**

芯片内部有电压调节器，会把 VDD 转换成较低的核心工作电压。图示结构中大约为 1.8 V，然后供给 CPU、存储器和数字外设。

<MermaidDiagram
  title="VDD 到核心电源的关系"
  chart={`flowchart LR
    A[VDD\n2.0V ~ 3.6V] --> B[内部电压调节器]
    B --> C[约 1.8V]
    C --> D[CPU 内核]
    C --> E[存储器]
    C --> F[数字外设]`}
/>

因此以后学习 Stop、Standby 时看到“电压调节器进入低功耗状态”或“核心域掉电”，就能知道它影响的是哪一部分。

## 3. VDDA 和 VSSA：为什么模拟部分单独供电？

`VDDA` 是芯片模拟部分的电源，`VSSA` 是模拟地。

图示器件中，VDDA 的电压范围也是：

```text
2.0 V ~ 3.6 V
```

VDDA 供电区域包括：

- ADC；
- DAC；
- 温度传感器；
- 部分复位电路；
- PLL 等模拟相关模块。

为什么不直接全部使用 VDD？

因为数字电路工作时会不断翻转，例如：

```text
GPIO 翻转
时钟切换
CPU 运算
总线访问
```

这些动作会在电源线上产生高频噪声。

ADC、DAC 属于模拟电路，对电源噪声非常敏感。如果直接和噪声较大的数字部分共用供电，可能影响转换精度。

所以可以简单理解成：

> **VDD 负责“吵闹的数字世界”，VDDA 尽量给“敏感的模拟世界”提供更干净的电源。**

实际硬件设计中，VDDA 附近通常还会配合去耦电容或滤波网络，具体连接方式要按照芯片数据手册推荐电路设计。

## 4. VREF+ 和 VREF-：ADC 的“尺子”

ADC 要把模拟电压转换成数字量，就必须有一个参考范围。

这个参考范围由：

```text
VREF+  → 参考电压上限
VREF-  → 参考电压下限
```

决定。

图示结构中：

- `VREF+` 是 ADC/DAC 的参考电压输入；
- `VREF-` 作为参考地，需要连接到 `VSSA`；
- VREF+ 的允许范围示意为约 `2.4 V ~ VDDA`。

可以把 ADC 想象成拿一把尺子测电压：

<MermaidDiagram
  title="ADC 参考电压的作用"
  chart={`flowchart LR
    LOW[VREF-\n测量下限] --> ADC[ADC 可测量范围]
    HIGH[VREF+\n测量上限] --> ADC
    ADC --> OUT[数字转换结果]`}
/>

如果参考电压不稳定，这把“尺子”的长度就在变化，最终 ADC 转换结果也会跟着变化。

因此：

> **VREF 的质量会直接影响 ADC/DAC 的精度。**

如果对模拟测量精度要求不高，很多设计会按照芯片手册把 VREF+ 与 VDDA 连接；如果精度要求较高，则可以考虑独立、低噪声、高精度的参考电压源。

## 5. VSS 和 VSSA 有什么区别？

这两个名字很像：

```text
VSS   → 数字地
VSSA  → 模拟地
```

VSSA 对应模拟供电域，VSS 对应数字供电域。

设计它们的目的仍然是减少数字噪声对模拟电路的干扰。

但“数字地和模拟地应该怎样连接”不能只靠一句“完全分开”来判断，实际 PCB 应按照具体 STM32 数据手册和参考设计处理。

对于初学阶段，先记住：

> **VSSA 是模拟部分的参考地，VREF- 通常连接 VSSA。**

## 6. VBAT：为什么主电源断了 RTC 还能走？

`VBAT` 是后备电源引脚。

图示器件中，其供电范围为：

```text
1.8 V ~ 3.6 V
```

VBAT 对应的是一个很小的**后备供电域**，其中通常包含：

- LSE 32.768 kHz 低速外部晶振；
- RTC；
- 后备寄存器；
- RCC 的部分后备域寄存器。

<MermaidDiagram
  title="VBAT 后备域"
  chart={`flowchart LR
    MAIN[VDD 正常] --> BACKUP[后备域]
    BAT[VBAT 后备电源] --> BACKUP
    BACKUP --> RTC[RTC]
    BACKUP --> LSE[LSE 32.768kHz]
    BACKUP --> REG[后备寄存器]
    BACKUP --> BDCR[RCC BDCR]`}
/>

这就是为什么很多 STM32 产品即使主系统掉电，只要 VBAT 还有电：

- RTC 仍然可以计时；
- 某些后备寄存器内容仍然可以保存。

这对低功耗设备非常重要。

例如电池设备可能让主系统绝大多数时间关闭，只保留 RTC 工作，到指定时间再唤醒系统。

## 7. 一张表先记住这些引脚

| 引脚 | 作用 | 主要供电对象 |
| --- | --- | --- |
| `VDD` | 数字电源 | I/O、待机电路、内部稳压器 |
| `VSS` | 数字地 | 数字电路参考地 |
| `VDDA` | 模拟电源 | ADC、DAC、温度传感器等 |
| `VSSA` | 模拟地 | 模拟电路参考地 |
| `VREF+` | ADC/DAC 参考电压上限 | 决定模拟转换量程和精度 |
| `VREF-` | ADC/DAC 参考电压下限 | 通常连接 VSSA |
| `VBAT` | 后备电源 | RTC、LSE、后备寄存器等 |

## 8. 这些内容和低功耗有什么关系？

现在可以建立一个最重要的低功耗思维：

```text
正常运行
  ↓
哪些模块不用？
  ↓
能不能停时钟？
  ↓
能不能停 CPU？
  ↓
能不能降低核心域功耗？
  ↓
哪些数据和时钟必须保留？
  ↓
RTC / 后备域是否还需要工作？
```

STM32 的低功耗模式并不是简单地“让 CPU 睡觉”。

真正需要理解的是：

> **不同低功耗模式关闭的资源不同，保留下来的电源域也不同，因此功耗、唤醒速度和数据保持能力也不同。**

下一部分将在这个基础上继续整理：

```text
Sleep
  ↓
Stop
  ↓
Standby
  ↓
各模式关闭了什么
  ↓
哪些寄存器 / SRAM 能保留
  ↓
RTC / EXTI / Wakeup Pin 如何唤醒
  ↓
进入和退出低功耗模式的代码
```
