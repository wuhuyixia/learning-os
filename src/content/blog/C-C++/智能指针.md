# C++ 智能指针

智能指针用于自动管理动态对象的生命周期，核心目标是减少手动 `new` / `delete` 带来的内存泄漏、重复释放和悬空指针问题。

## 1. unique_ptr

`std::unique_ptr` 表示独占所有权，同一时刻只有一个智能指针负责管理对象。

## 2. shared_ptr

`std::shared_ptr` 通过引用计数实现共享所有权，当最后一个 `shared_ptr` 被销毁时，对象才会被释放。

## 3. weak_ptr

`std::weak_ptr` 不增加引用计数，主要用于观察由 `shared_ptr` 管理的对象，并解决循环引用问题。

## 4. 典型区别

- `unique_ptr`：独占资源，开销小，优先使用。
- `shared_ptr`：多个对象需要共享同一资源时使用。
- `weak_ptr`：配合 `shared_ptr` 使用，用于避免循环引用。
