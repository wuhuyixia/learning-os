# C++ 基础：继承与派生

这篇笔记按照课件《第4章 继承与派生》的顺序整理。目标只有一个：**用最少的概念，看懂继承到底在解决什么问题。**

![继承总览](/image/CPP/inheritance-overview.svg)

---

## 1. 继承是什么？

课件给出的核心定义是：

> 在已有类（基类）的基础上创建新类，新类称为派生类。

例如：

```text
Person
  ↓
Student
```

可以理解成：

- `Person` 已经有姓名、年龄等成员；
- `Student` 在此基础上继续增加年级等成员；
- 不需要把 `Person` 的内容重新写一遍。

### 单继承与多继承

**单继承：一个派生类来自一个基类。**

```text
Person
  ↓
Student
```

**多继承：一个派生类同时来自两个或更多基类。**

```text
Student      Employee
    \        /
     \      /
   StudentHasJob
```

一句话记忆：

> **继承 = 在已有类的基础上继续扩展。**

---

## 2. 派生类怎么声明？

单继承基本格式：

```cpp
class 派生类名 : 继承方式 基类名
{
    // 派生类自己的成员
};
```

例如：

```cpp
class Student : public Person
{
    int grade;
};
```

这里：

```text
Person   → 基类
Student  → 派生类
public   → 继承方式
```

课件列出了三种继承方式：

```cpp
class A : public Base {};
class B : protected Base {};
class C : private Base {};
```

---

## 3. public、protected、private 怎么记？

这是本章最容易混淆的地方。

先看课件总结：

| 基类成员 | public继承后 | protected继承后 | private继承后 |
|---|---|---|---|
| `public` | public | protected | private |
| `protected` | protected | protected | private |
| `private` | 不可直接访问 | 不可直接访问 | 不可直接访问 |

最重要的一条：

> **基类的 private 成员，在派生类中不能直接访问。**

可以这样记：

```text
public
  ↓
protected
  ↓
private
  ↓
不可直接访问
```

继承方式会“收紧”访问权限，但不会把原来更严格的权限变宽。

## 4. 构造函数和析构函数怎么执行？

基类的构造函数和析构函数**不能被继承**。

创建派生类对象时，需要先把“基类部分”构造好，再构造“派生类部分”。

![构造析构顺序](/image/CPP/ctor-order.svg)

课件给出的构造顺序：

```text
① 基类构造函数
② 对象成员构造函数（如果有）
③ 派生类构造函数
```

析构正好相反：

```text
① 派生类析构函数
② 对象成员析构函数
③ 基类析构函数
```

### 有参数的基类构造函数

如果基类需要参数，派生类要通过**成员初始化列表**显式调用：

```cpp
class Person
{
public:
    Person(string name, int age);
};

class Student : public Person
{
public:
    Student(string name, int age, int grade)
        : Person(name, age)
    {
        // 初始化 Student 自己的部分
    }
};
```

一句话记忆：

> **构造：先父后子；析构：先子后父。**

## 5. 多继承

多继承声明格式：

```cpp
class 派生类
    : public 基类1,
      public 基类2
{
};
```

课件中的例子：

```text
Student + Employee
        ↓
 StudentHasJob
```

也就是“学生”和“在职人员”的信息一起组成“在职学生”。

### 多继承的构造顺序

如果同时继承多个基类：

```cpp
class StudentHasJob
    : public Student,
      public Employee
{
};
```

构造时：

```text
Student 构造
      ↓
Employee 构造
      ↓
StudentHasJob 构造
```

课件特别强调：

> 多个基类构造函数的执行顺序，取决于**派生类声明时基类出现的顺序**，而不是成员初始化列表里的书写顺序。

析构顺序仍然完全相反。

---

## 6. 多个基类有同名成员怎么办？

如果两个基类里都有同名成员：

```text
BaseA::show()
BaseB::show()
```

派生类直接写 `show()` 就可能发生冲突。

解决办法是使用：

```cpp
基类名::成员名
```

例如：

```cpp
BaseA::show();
BaseB::show();
```

这就是课件里的**成员名限定法**。

一句话记忆：

> **同名了，就把“姓”也写出来。**

## 7. 菱形继承与虚基类

这一部分是本章最重要的图。

![虚基类](/image/CPP/diamond-virtual-base.svg)

课件中的结构可以简化成：

```text
          Person
         /      \
    Student   Employee
         \      /
      StudentHasJob
```

问题是：

```text
Student 里有一份 Person
Employee 里也有一份 Person
```

于是最终的 `StudentHasJob` 里可能出现**基类成员的多个副本**。

课件给出的解决方式是：**虚基类**。

基本格式：

```cpp
class Student : virtual public Person
{
};

class Employee : virtual public Person
{
};
```

核心作用：

> 让共同的基类在最终派生类对象中只保留一份。

### 虚基类初始化

课件强调两点：

1. 真正创建最终对象的那个类，负责实际调用虚基类构造函数；
2. 如果初始化列表同时包含虚基类和普通基类，虚基类先构造。

---

## 8. 赋值兼容性

课件最后总结了三条规则。

### 对象

派生类对象可以赋值给基类对象：

```cpp
Base b;
Derived d;

b = d;
```

### 指针

基类指针可以指向派生类对象：

```cpp
Base *p = &d;
```

### 引用

基类引用可以引用派生类对象：

```cpp
Base &r = d;
```

记忆成一条：

```text
派生类对象
   ↓
可以当作基类对象使用
```

## 9. 一页复习

| 知识点 | 最短记忆 |
|---|---|
| 基类 | 已有的类 |
| 派生类 | 在基类上继续扩展的新类 |
| 单继承 | 一个基类 |
| 多继承 | 多个基类 |
| public继承 | 基类 public 仍为 public |
| protected继承 | public 会变为 protected |
| private继承 | public/protected 都变为 private |
| 构造顺序 | 基类 → 对象成员 → 派生类 |
| 析构顺序 | 派生类 → 对象成员 → 基类 |
| 同名冲突 | `基类名::成员名` |
| 虚基类 | 避免共同基类出现多个副本 |
| 赋值兼容 | 派生类对象可按基类使用 |
