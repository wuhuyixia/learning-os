# 指针

指针本质上是一个**保存内存地址的变量**。普通变量保存数据，指针变量保存“数据在哪里”。

例如：

```c
int a = 10;
int *p = &a;
```

<PointerBasicRoughDemo />

其中：

- `&a`：取得变量 `a` 的地址；
- `p`：保存 `a` 的地址；
- `*p`：访问该地址中的数据。

因此 `*p = 20;` 等价于通过地址把 `a` 修改为 `20`。

## 指向指针的指针（二级指针）

指针本身也是变量，因此它也有自己的地址。于是可以再用一个指针保存另一个指针的地址：

```c
int x = 5;
int *p = &x;
int **q = &p;
```

关系就是 `q → p → x`。

<PointerToPointerRoughDemo />

其中 `*q` 得到 `p`，`**q` 最终访问 `x`。因此 `**q = 8;` 等价于 `x = 8;`。

## 1. 指针函数

如果函数返回值是指针，例如：

```c
int *get_data(void);
```

它就是**指针函数**。需要特别注意：不能安全地返回普通局部变量的地址。

```c
int *func(void)
{
    int a = 10;
    return &a;
}
```

`a` 位于 `func()` 的栈帧中，函数返回后生命周期结束，此时返回出去的地址就变成悬空地址。

## 2. 函数指针

函数同样有入口地址，**函数指针就是保存函数入口地址的指针**。

```c
int func(int a)
{
    int b = 10;
    return a * b;
}

int (*pa)(int) = func;
int result = pa(10);
```

从变量名 `pa` 开始看：`(*pa)` 表示 `pa` 是指针，后面的 `(int)` 表示它指向一个参数为 `int` 的函数，最前面的 `int` 表示函数返回 `int`。

下面两种声明完全不同：

```c
int *pa(int);      // 指针函数：函数返回 int *
int (*pa)(int);    // 函数指针：指针指向函数
```

复杂函数指针通常用 `typedef` 简化：

```c
typedef int (*FuncPtr)(int);
FuncPtr pa = func;
```

在嵌入式中常用于**回调函数、状态机、驱动接口、命令分发表和中断接口**。

## 3. 数组与指针

数组在内存中是一段**连续的同类型空间**。理解数组与指针时只需要抓住一个核心：

> **指针 `+1` 跨多少字节，由它当前指向的完整目标类型决定。**

### 3.1 一维数组

```c
int arr[3] = {1, 2, 3};
```

假设 `sizeof(int)=4`、`arr[0]` 地址为 `0x1100`，那么三个元素依次位于 `0x1100、0x1104、0x1108`。

在普通表达式中，`arr` 通常退化为首元素指针，因此 `arr` 与 `&arr[0]` 都指向第一个元素；但 `&arr` 的类型是 `int (*)[3]`，所以三者虽然起始地址数值可相同，类型和步长不同。

| 表达式 | 类型/含义 | `+1` 的步长 |
| :--- | :--- | :--- |
| `arr` | `int *`，指向首元素 | `sizeof(int)` |
| `&arr[0]` | `int *` | `sizeof(int)` |
| `&arr` | `int (*)[3]`，指向整个数组 | `sizeof(int[3])` |

<PointerArrayRoughDemo />

因此 `arr + 1` 跳到 `arr[1]`，而 `&arr + 1` 会直接跨过整个数组。

### 3.2 二维数组

```c
int B[2][3] = {
    {2, 3, 6},
    {4, 5, 8}
};
```

`B` 的完整类型是 `int[2][3]`，可以理解为“2 个 `int[3]` 组成的数组”。虽然逻辑上分成两行，6 个 `int` 在内存中仍连续排列。

假设 `sizeof(int)=4` 且 `B` 从地址 400 开始：第一行占 12 字节，所以 `B+1` 会从 400 跳到 412。

<Pointer2DArrayRoughDemo />

二维数组最关键的关系可以直接放在一张表里：

| 表达式 | 常见类型 | 含义 |
| :--- | :--- | :--- |
| `B` | `int (*)[3]` | 指向第 0 行 |
| `B + 1` | `int (*)[3]` | 指向第 1 行 |
| `*B` / `B[0]` | `int[3]`，常退化为 `int *` | 第 0 行 |
| `B[1] + 2` | `int *` | 指向 `B[1][2]` |
| `&B[1][2]` | `int *` | 直接取得该元素地址 |

数组下标本质上仍然是指针运算：

```c
B[i][j] == *(*(B + i) + j)
```

所以示例中：`B[1][2] == *(*(B+1)+2) == 8`。这一步包含两次移动：先按“一整行”移动，再按“单个 int”移动。

如果定义 `int (*p)[3] = B;`，那么 `p[1][2]` 与 `B[1][2]` 访问的是同一个元素。

### 3.3 三维数组

三维数组只是再向外套一层数组：

```c
int C[3][2][2] = {
    {{2, 5}, {7, 9}},
    {{3, 4}, {6, 1}},
    {{0, 8}, {11, 13}}
};
```

可以按层级理解：`C` 包含 3 个 `int[2][2]` 平面；每个平面包含 2 个 `int[2]`；每一行最终包含 2 个 `int`。

假设 `sizeof(int)=4` 且 `C=800`，则每个 `2×2` 平面占 16 字节，因此 `C+1=816`、`C+2=832`。

<Pointer3DArrayRoughDemo />

每进入一层，目标类型就少一维：

| 表达式 | 常见表达式类型 | `+1` 步长 |
| :--- | :--- | :--- |
| `C` | `int (*)[2][2]` | 16 B |
| `C[0]` / `*C` | `int (*)[2]` | 8 B |
| `C[0][0]` / `**C` | `int *` | 4 B |
| `C[0][0][0]` / `***C` | `int` | 已是值 |

因此：

```c
C[i][j][k] == *(*(*(C + i) + j) + k)
```

例如 `C[1][1][0]`：先从 800 跨一个平面到 816，再跨一行到 824，最后取得地址 824 中的 `int`，结果为 `6`。

<Pointer3DArrayLifecycleDemo />

### 3.4 多维数组作为函数参数

数组作为函数参数时，第一维会被调整为指针，但编译器仍必须知道后续维度，才能计算步长：

```c
void f1(int a[], int n);              // 等价于 int *a
void f2(int a[][3], int rows);        // 等价于 int (*a)[3]
void f3(int a[][2][2], int blocks);   // 等价于 int (*a)[2][2]
```

所以可以记成：**第一维可以省略，后续维度通常必须明确。**

<PointerArrayArgumentRoughDemo />

对于一维数组参数，`sizeof(a)` 得到的是指针大小，而不是调用者整个数组大小，因此长度通常需要额外传入。

## 4. 值传递与 swap

C 语言函数参数默认采用**值传递**。调用函数时，形参得到的是实参当前值的一份副本。

```c
void swap(int x, int y)
{
    int temp = x;
    x = y;
    y = temp;
}

int main(void)
{
    int a = 10;
    int b = 20;
    swap(a, b);
}
```

这里交换的只是 `x`、`y` 两个副本，`main()` 中的 `a`、`b` 不会改变。

<PointerPassByValueRoughDemo />

如果希望真正修改调用者中的变量，就把地址传进去：

```c
void swap(int *x, int *y)
{
    int temp = *x;
    *x = *y;
    *y = temp;
}

int main(void)
{
    int a = 10;
    int b = 20;
    swap(&a, &b);
}
```

形参依然是值传递，只不过这次复制的是地址；`*x` 和 `*y` 通过地址访问到原来的 `a` 和 `b`。

> **C 语言没有把普通参数“按引用传递”；通过指针修改变量，本质仍然是“把地址这个值传进去”。**

## 5. 悬空指针

悬空指针（Dangling Pointer）指的是：指针仍保存一个地址，但该地址对应的对象已经失效。

典型情况包括：

- 返回局部变量地址；
- `free()` 后继续使用旧指针；
- 对象生命周期结束后仍然保存其地址。

如果确实需要返回函数内部对象的地址，应保证对象生命周期足够长，例如：

```c
int *func(void)
{
    static int a = 10;
    return &a;
}
```

`static` 局部变量不会随着函数返回而销毁，因此返回它的地址是有效的。

## 6. 一句话理解

```text
普通变量：保存数据
指针变量：保存地址
*p：访问地址中的数据
```

几个容易混淆的声明可以这样看：

```text
int *func(void);    函数 → 返回 int *
int (*pa)(int);     指针 → 指向函数
int *pa;            指针 → 指向 int
int **q;            二级指针 → 指向 int *
int (*pArr)[3];     指针 → 指向 int[3]
```

参数传递还可以这样记：

```text
swap(a, b)      → 复制 10、20，改的是副本
swap(&a, &b)    → 复制地址，通过 * 解引用修改原变量
```

真正需要记住的是：**先看变量名，再看它首先和谁结合；同时始终关注指针的目标类型，以及函数参数实际传进去的是“数据值”还是“地址值”。**
