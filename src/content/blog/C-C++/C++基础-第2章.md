# C++ 基础：从名字空间一路学到异常处理

这篇笔记按照《第2章 C++基础》的顺序整理，目标不是死背语法，而是先弄清楚“它解决什么问题”，再看代码。

> **代码说明：** 课件中的部分示例使用了较早期的 `iostream.h` 写法。本文为了方便在当前编译器中练习，代码统一写成标准的 `#include <iostream>`、`#include <string>` 形式；知识点和课件保持一致。

## 学习路线图

```text
名字空间 namespace
        ↓
数据类型：bool / string / const
        ↓
指针：地址 & 与解引用 *
        ↓
动态内存：new / delete
        ↓
引用：给变量起“别名”
        ↓
函数：定义、默认参数、参数传递、inline、重载
        ↓
异常处理：try → throw → catch
```

只要把这条链走通，后面再学习类、对象、STL 和嵌入式 C++ 会轻松很多。

## 1. 名字空间 namespace

### 1.1 为什么需要名字空间？

先想一个很生活化的场景：学校里可能有两个同名同学。如果只喊名字，就不知道说的是谁；如果写成“计算机学院::张三”和“自动化学院::张三”，就不会冲突。

C++ 的 `namespace` 做的事情很像：**给一组名字划分作用域，避免不同代码中的同名变量、函数发生冲突。**

```cpp
#include <iostream>

namespace A {
    int value = 10;
}

namespace B {
    int value = 20;
}

int main() {
    std::cout << A::value << std::endl;
    std::cout << B::value << std::endl;
    return 0;
}
```

可以把它画成：

```text
              value
                │
        ┌───────┴────────┐
        │                │
 namespace A        namespace B
 value = 10         value = 20
        │                │
    A::value          B::value
```

### 1.2 名字空间怎么定义？

基本形式：

```cpp
namespace 名字空间名称 {
    // 变量、函数、类型等
}
```

课件强调：名字空间可以定义在全局作用域中，也可以嵌套在另一个名字空间中，但不能定义在函数或类的内部。

### 1.3 三种使用方式

第一种最明确：每次都写完整名字。

```cpp
std::cout << "hello" << std::endl;
```

第二种：把整个名字空间引入当前作用域。

```cpp
using namespace std;
cout << "hello" << endl;
```

第三种：只引入一个具体名字。

```cpp
using std::cout;
using std::endl;

cout << "hello" << endl;
```

> **一句话记忆：** `A::x` 就是“去 A 这个名字空间里找 x”。

## 2. 数据类型：先抓住 bool、string 和 const

课件把 C++ 数据类型分成基本数据类型和非基本数据类型。这里先抓住本章新增或重点强调的三个内容。

### 2.1 bool：只有真和假

布尔类型使用 `bool` 表示，只有两个值：`true` 和 `false`。

```cpp
#include <iostream>
using namespace std;

int main() {
    bool flag = true;

    if (flag) {
        cout << "flag is true" << endl;
    }

    flag = false;
    return 0;
}
```

常见用途是表示“是否成立”“是否完成”“是否找到”。例如：

```cpp
bool isPrime(int x);
bool isLeap(int year);
```

你可以把 `bool` 理解成程序里的开关：

```text
true  ──► 开
false ──► 关
```

### 2.2 string：更方便地处理字符串

C++ 除了可以继续使用字符数组，还提供标准字符串类 `string`。使用它需要包含 `<string>` 头文件。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Alice";
    string hello = "Hello, " + name;

    cout << hello << endl;
    return 0;
}
```

`string` 可以直接完成复制、比较、连接、查找和取子串等常见字符串操作。

需要区分两个头文件：

| 头文件 | 作用 |
| --- | --- |
| `<string>` | 提供 C++ 的 `string` 类型 |
| `<cstring>` | 提供传统 C 风格字符串处理函数 |

### 2.3 const：定义不能再修改的对象

常量可以这样定义：

```cpp
const float Pi = 3.14159f;
```

也可以写成：

```cpp
float const Pi = 3.14159f;
```

初始化以后，就不应该再修改：

```cpp
Pi = 3.0f;  // 错误：Pi 是常量
```

> **一句话记忆：** `const` 就像给变量贴上“只读”标签。

## 3. 从指针理解 new 和 delete

### 3.1 指针到底是什么？

一个变量如果专门用来保存另一个对象的地址，就称为指针变量。

```cpp
int i = 36;
int *p = &i;
```

这里有两个最重要的运算符：

| 运算符 | 含义 |
| --- | --- |
| `&` | 取地址 |
| `*` | 访问指针指向的对象，也叫解引用 |

可以想象成：

```text
变量 p                         变量 i
┌──────────────┐              ┌──────────────┐
│ 保存 i 的地址 │ ───────────► │      36      │
└──────────────┘              └──────────────┘

p      ：地址
*p     ：地址里的值，也就是 i
&i     ：i 的地址
```

因此：

```cpp
*p = 95;
```

并不是修改 `p` 本身，而是顺着 `p` 保存的地址找到 `i`，把 `i` 改成 `95`。

### 3.2 为什么指针声明时要写类型？

例如：

```cpp
int   *p1;
char  *p2;
float *p3;
```

指针不仅要知道“地址是多少”，还要知道“这个地址里的数据应该按什么类型解释”。

### 3.3 new：运行时申请内存

最基本的形式：

```cpp
int *p = new int;
```

可以理解为：

```text
程序运行
   │
   ├──► new int
   │        │
   │        └──► 申请一块能放 int 的内存
   │
   └──► 把这块内存的地址交给 p
```

给它赋值：

```cpp
*p = 10;
```

也可以在申请时初始化：

```cpp
int *p = new int(10);
```

申请数组：

```cpp
int *p = new int[10];
```

### 3.4 delete：释放 new 得到的内存

单个对象：

```cpp
int *p = new int(10);
delete p;
p = nullptr;
```

数组必须对应使用 `delete[]`：

```cpp
int *p = new int[10];
delete[] p;
p = nullptr;
```

最重要的对应关系：

| 申请 | 释放 |
| --- | --- |
| `new T` | `delete p` |
| `new T[n]` | `delete[] p` |

课件提醒的核心是：申请内存后要关注是否成功，并在不再需要时及时释放。释放后不要继续使用原来的地址。

> **现代 C++ 补充：** 课件示例中使用 `NULL`，本文代码使用当前 C++ 更常见的 `nullptr`。这属于写法更新，不改变本章对“释放后不要再把它当有效地址使用”的理解。

## 4. 引用：给已有变量起一个别名

### 4.1 引用是什么？

引用通常被理解为某个变量的“别名”。

```cpp
int i = 5;
int &j = i;
```

这时 `i` 和 `j` 操作的是同一个对象。

```text
          同一块数据
             5
          ┌─────┐
i ───────►│     │
j ───────►│     │
          └─────┘
```

试一下：

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 30;
    int &j = i;

    cout << i << " " << j << endl;
    j = 80;
    cout << i << " " << j << endl;

    cout << &i << endl;
    cout << &j << endl;
    return 0;
}
```

你会发现修改 `j` 后 `i` 也变了，而且 `&i` 与 `&j` 对应同一个对象。

### 4.2 引用的两个关键规则

引用声明时必须立即初始化：

```cpp
int i;
int &j = i;  // 正确
```

不能先声明一个“空引用”再绑定。

引用绑定之后，也不能改成另一个变量的别名。下面这段代码：

```cpp
int i = 1;
int k = 2;
int &j = i;
j = k;
```

最后一行的含义不是“让 j 改为引用 k”，而是把 `k` 的值赋给 `i`。

### 4.3 函数也可以返回引用

形式：

```cpp
类型名 &函数名(参数表);
```

课件强调：如果返回的是引用，被引用的对象必须在函数结束后仍然有效。课件示例使用全局对象来保证这一点。

```cpp
int maxab;

int &maxRef(int x, int y) {
    if (x > y)
        maxab = x;
    else
        maxab = y;

    return maxab;
}
```

> **核心理解：** 返回引用不是返回一份拷贝，而是把某个实际对象本身交给调用者继续访问，所以必须保证那个对象还活着。

## 5. 函数

本章函数部分包括：定义与调用、函数原型与默认参数、参数传递、内联函数和函数重载。

### 5.1 函数的定义与调用

一般形式：

```cpp
返回值类型 函数名(形式参数表) {
    // 函数体
}
```

例如：

```cpp
int getSum(int x, int y) {
    return x + y;
}

int main() {
    int result = getSum(3, 4);
    return 0;
}
```

函数调用时，实参与形参的个数和类型需要能够对应。

### 5.2 函数原型与默认参数

可以先声明函数，再在后面定义：

```cpp
int getSum(int a, int b);

int main() {
    int sum = getSum(1, 2);
    return 0;
}

int getSum(int a, int b) {
    return a + b;
}
```

默认参数可以这样写：

```cpp
int getSum(int a = 3, int b = 10);
```

此时：

```cpp
getSum();      // 使用 3 和 10
getSum(5);     // a = 5，b 使用 10
getSum(5, 6);  // a = 5，b = 6
```

默认参数要从参数表的右侧连续提供，不能左边有默认值而右边没有。

### 5.3 最重要的一节：三种参数传递

课件用“交换两个整数”比较了三种方式。

#### 方式一：值传递

```cpp
void swapValue(int x, int y) {
    int temp = x;
    x = y;
    y = temp;
}
```

调用：

```cpp
int a = 3;
int b = 4;
swapValue(a, b);
```

可以把它理解成：

```text
main 中：       a = 3    b = 4
                  │        │
                 复制      复制
                  ↓        ↓
函数中：          x = 3    y = 4

交换的只是 x 和 y
a、b 本身没有被交换
```

#### 方式二：地址传递

```cpp
void swapPointer(int *x, int *y) {
    int temp = *x;
    *x = *y;
    *y = temp;
}
```

调用时把地址传进去：

```cpp
swapPointer(&a, &b);
```

此时 `x` 指向 `a`，`y` 指向 `b`，通过 `*x`、`*y` 可以直接修改原变量。

#### 方式三：引用传递

```cpp
void swapReference(int &x, int &y) {
    int temp = x;
    x = y;
    y = temp;
}
```

调用：

```cpp
swapReference(a, b);
```

`x`、`y` 分别成为 `a`、`b` 的别名，因此可以直接交换原变量。

三种方式放在一起看：

| 方式 | 形参写法 | 能否直接修改实参 |
| --- | --- | --- |
| 值传递 | `int x` | 否，操作的是副本 |
| 地址传递 | `int *x` | 可以，通过 `*x` |
| 引用传递 | `int &x` | 可以，x 是原对象的别名 |

这是本章最值得反复画图理解的地方。

### 5.4 inline 内联函数

课件引入 `inline` 的目的，是希望减少简单函数调用带来的额外开销。

```cpp
inline double circle(double r) {
    return 3.1416 * r * r;
}
```

调用方式和普通函数相同：

```cpp
double area = circle(2.0);
```

课件还强调：`inline` 更适合短小、简单的函数，它只是给编译器的建议；函数过于复杂时，编译器仍可能按普通函数处理。

### 5.5 函数重载

同一个函数名，可以根据参数个数、类型或类型顺序的不同，定义多个版本。

参数个数不同：

```cpp
int sum(int x, int y) {
    return x + y;
}

int sum(int x, int y, int z) {
    return x + y + z;
}
```

参数类型不同：

```cpp
int cube(int x) {
    return x * x * x;
}

float cube(float x) {
    return x * x * x;
}
```

参数顺序不同：

```cpp
double sum(int x, double y) {
    return x + y;
}

double sum(double x, int y) {
    return x + y;
}
```

编译器会根据调用时的参数选择合适的版本。

需要特别注意：**不能只靠返回类型区分重载。**

```cpp
float  cube(float x);
double cube(float x);  // 非法：参数表完全相同
```

另外，重载和默认参数同时出现时，也要注意调用是否产生二义性。

## 6. 异常处理：try、throw、catch

程序运行时可能遇到可以预料但难以完全避免的问题，例如除数为零、文件打开失败、动态内存分配失败等。

C++ 的异常处理可以用三个词记住：

```text
try
 │
 │  先执行可能出问题的代码
 ↓
throw
 │
 │  出现异常时抛出信息
 ↓
catch
    找到匹配的处理器进行处理
```

### 6.1 基本结构

```cpp
try {
    // 被检查的代码
}
catch (类型1 参数1) {
    // 处理类型1异常
}
catch (类型2 参数2) {
    // 处理类型2异常
}
catch (...) {
    // 捕获其他异常
}
```

### 6.2 一个最直观的除法例子

```cpp
#include <iostream>
using namespace std;

double divide(int a, int b) {
    if (b == 0) {
        throw b;
    }
    return static_cast<double>(a) / b;
}

int main() {
    try {
        cout << divide(10, 0) << endl;
    }
    catch (int) {
        cout << "除数不能为 0" << endl;
    }

    return 0;
}
```

执行到 `throw` 时，`try` 中后面的剩余语句会被跳过，程序去寻找匹配的 `catch`。

### 6.3 异常执行流程

课件给出的执行过程可以压缩成下面四步：

```text
① 顺序执行 try 中的代码
        │
        ├── 没有异常 ──► 跳过 catch，继续往后执行
        │
        └── 出现异常
                │
                ↓
② throw 抛出异常信息
                │
                ↓
③ 寻找类型匹配的 catch
                │
                ↓
④ 执行 catch，然后继续执行 catch 后面的代码
```

一个 `try` 后面可以跟多个 `catch`；`catch (...)` 可以作为兜底处理。如果抛出的异常始终找不到匹配处理器，程序会终止。

最后不要再按“六个孤立知识点”去记，而是把它们连成一张图：

```text
namespace
解决“名字冲突”
    │
    ↓
bool / string / const
解决“数据怎么表示、字符串怎么管理、哪些值不能改”
    │
    ↓

    │

    │
    ↓

    │
    ↓
函数
理解“代码如何封装、参数到底传了什么”

    ↓

```

3. 自己制造一次“除数为 0”，观察 `throw` 后 `try` 中的代码是否继续执行。
